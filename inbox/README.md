# 收件箱 — 使用说明

## 工作方式

每个子文件夹 = **一门课程**。把该课程的所有课件文件（PDF/PPTX）放进去，然后让 AI 逐份处理。

## 用法

### 创建新课程

直接在 inbox/ 下新建文件夹，把课件拖进去：

```
inbox/
├── 数据结构与算法/
│   ├── 第一章-绪论.pdf
│   ├── 第二章-线性表.pptx
│   └── 第三章-栈和队列.pdf
├── 操作系统/
│   ├── lecture01.pdf
│   └── lecture02.pptx
└── 线性代数/
    └── ...
```

### 处理课程资料

```
/learn inbox/数据结构与算法/               # 批量处理该课程下所有未处理的文件
/learn inbox/数据结构与算法/第一章.pdf       # 只处理单个文件
/learn inbox/数据结构与算法/ --resume       # 从上次中断的位置继续
/learn inbox/数据结构与算法/ --single       # 每天学一章
```

### 深度学习和提问

生成笔记后，用 `/study` 进行深度问答，对话中的洞察会自动沉淀到笔记：

```
/study start 数据结构与算法                 # 进入问答模式（加载全部笔记）
/study start 数据结构与算法 --chapter 3     # 聚焦栈和队列这一章
# ... 像聊天一样随意提问 ...
/study done                                 # 结束：AI 提取洞察，追加到对应笔记
```

### 进度追踪

每个课程文件夹里会有一个 `.learned` 文件（自动生成），记录已处理的文件。下次运行 `/learn` 时会自动跳过，只处理新增的。

### 课程文件夹放什么

- PDF/PPTX 课件、教材章节
- 截图（板书、PPT）
- 从网页保存的文章
- 作业要求和批改反馈
