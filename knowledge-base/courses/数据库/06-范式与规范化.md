## 一句话总结

规范化是一个**逐级消除不良函数依赖**的过程：**1NF → 2NF（消除非主属性对码的部分依赖）→ 3NF（消除非主属性对码的传递依赖）→ BCNF（消除主属性对码的部分/传递依赖）**——每一级都解决了上一级存在的特定异常。

## 核心概念

### 范式层级关系

```
1NF ⊃ 2NF ⊃ 3NF ⊃ BCNF ⊃ 4NF ⊃ 5NF
```

每一级范式比上一级更严格（约束条件更强）。

### 2NF（第二范式）

**定义 6.6**：R ∈ 1NF，且**每一个非主属性都完全函数依赖于任何一个候选码**。

反例：SLC(Sno, Sdept, Sloc, Cno, Grade)，候选码 (Sno, Cno)
- Sdept 只需 Sno 就能确定（部分依赖）→ 不满足 2NF

解决：将 SLC 分解为 SL(Sno, Sdept, Sloc) 和 SC(Sno, Cno, Grade)。

**2NF 消除的问题**：部分依赖造成的插入/删除/更新异常。

### 3NF（第三范式）

**定义 6.7**：R ∈ 2NF，且**每一个非主属性都不传递依赖于任何一个候选码**。

反例：SL(Sno, Sdept, Sloc)，候选码 Sno
- Sno → Sdept, Sdept → Sloc → 传递依赖！（Sloc 通过 Sdept 间接依赖于 Sno）

解决：分解为 S(Sno, Sdept) 和 D(Sdept, Sloc)。

> **注意**：Sloc → Sdept 成立时（一个住处只对应一个系），传递依赖就不是问题——传递依赖的判断取决于实际语义！

### BCNF（Boyce-Codd 范式）

**定义 6.8**：R ∈ 3NF，且对于 R 中的**每一个函数依赖 X → Y（Y ⊈ X），X 都必须包含候选码**。

换句话说：**所有非平凡函数依赖的决定因素都是超码**。

BCNF 解决了 3NF 无法解决的异常：当关系存在多个候选码且候选码之间有重叠时，3NF 仍可能存在问题。BCNF 是比 3NF 更强的范式。

### 范式判断速查

| 检查内容 | 不满足说明 |
|----------|-----------|
| 1NF | 所有属性原子性 | 存在表中套表 |
| 2NF | 非主属性对任一个候选码完全依赖 | 存在部分依赖 |
| 3NF | 非主属性对任一个候选码无传递依赖 | 存在传递依赖 |
| BCNF | 所有非平凡函数依赖的决定因素都含候选码 | 存在"非超码决定属性"的情况 |

## 难点突破

### BCNF 分解算法——怎么拆？

**口诀**：找到肇事依赖 X→Y，算 X⁺，沿 X⁺ 边界一刀两半，X 留在两边当桥梁。

具体步骤（算法 6.5）：
1. 找到违反 BCNF 的依赖 X→Y（X 不是超码的那个）
2. 计算 X 的闭包 X⁺
3. 拆成两个子模式：**(X⁺)** 和 **((U − X⁺) ∪ X)**
4. X 出现在两边——这是保证无损连接的关键（X 在左边子模式是超码，公共属性 X 能决定左边全部 → 引理 6.5 保证无损）
5. 对每个子模式递归检查，直到全部满足 BCNF
6. 最后去重：子模式被另一子模式包含就删掉

**实例**：R3(B,C,D,F)，FD = {DF→BC, B→D}，候选码 DF 和 BF
- B→D 违反 BCNF（B 不是超码）
- B⁺ = {B, D}
- 拆：(B,D) + (B,C,F) → R31 被 R2(A,B,D) 包含，删掉 → 最终 R3(B,C,F)
- R3 上的新 FD：由 B→D 和 DF→BC 推导出 BF→C（增广 + 传递）

> 详细推导见 `06-模式分解.md` 示例考题。

### 3NF vs BCNF——什么时候 3NF 够了，什么时候必须 BCNF？

**突破方法**：3NF 能消除非主属性造成的异常，但**主属性之间的依赖**仍可能出问题。

典型场景：STC(S, T, C) — 学生 S 选课 C，教师 T 教课 C，一个课只有一位老师教。
- 候选码：(S, C) 和 (S, T)（一个学生跟一位老师只能上一门课）
- 函数依赖：T → C（一位老师只教一门课）
- 检查 3NF：T 是主属性（属于候选码 (S,T)），C 也是主属性 → 涉及主属性的依赖不影响 3NF → **满足 3NF**
- 检查 BCNF：T → C，但 T 不是超码 → **不满足 BCNF**！

这就是 3NF 够用但 BCNF 能捕捉到的"主属性之间的依赖异常"。

## 记忆卡片

**Q1: 2NF/3NF/BCNF 各消除什么？**
A1: 2NF 消除部分函数依赖；3NF 消除传递函数依赖；BCNF 消除所有"决定因素不是超码"的函数依赖。三者是逐级包含的关系。

**Q2: 判断 2NF 的步骤？**
A2: ①找出所有非主属性和所有候选码 ②检查每个非主属性对每个候选码是否存在部分依赖（去掉候选码中某些属性后仍能决定该非主属性）。

**Q3: 3NF 满足但 BCNF 不满足的典型例子？**
A3: STC(学生, 教师, 课程)，候选码 (S,C) 和 (S,T)，T→C。T 是主属性所以不影响 3NF，但 T 不是超码所以违反 BCNF。

### 简答题（期末笔试模拟）

**Q1: 简述 2NF、3NF、BCNF 各自消除什么问题，三者是什么关系。**

> 参考答案：2NF 消除非主属性对码的部分函数依赖；3NF 消除非主属性对码的传递函数依赖；BCNF 消除决定因素不含码的非平凡函数依赖（包括主属性造成的问题）。三者逐级包含：BCNF ⊂ 3NF ⊂ 2NF ⊂ 1NF，即 BCNF 是最严格的范式。

**Q2: 为什么 SLC(Sno, Sdept, Sloc, Cno, Grade) 不满足 2NF？如何分解？**

> 参考答案：候选码 (Sno, Cno)。非主属性 Sdept 和 Sloc 仅依赖于 Sno（候选码的真子集），存在部分函数依赖 → 违反 2NF。分解：SC(Sno, Cno, Grade) + SL(Sno, Sdept, Sloc)，分解后 Sdept/Sloc 的候选码变为 Sno，不再有部分依赖。

**Q3: SL(Sno, Sdept, Sloc) 满足 2NF 为什么不满足 3NF？如何分解？**

> 参考答案：候选码 Sno。Sno → Sdept, Sdept → Sloc（且 Sdept ↛ Sno），Sloc 传递依赖于 Sno → 违反 3NF。分解：S-D(Sno, Sdept) + D-L(Sdept, Sloc)。

**Q4: STC(S, T, C) 为什么满足 3NF 但不满足 BCNF？**

> 参考答案：候选码 (S, C) 和 (S, T)，函数依赖 T → C。检查 3NF：T 是主属性（包含在候选码 (S,T) 中），C 也是主属性（包含在候选码 (S,C) 中），不存在非主属性的传递依赖 → 满足 3NF。检查 BCNF：T → C 是非平凡依赖（C ⊈ T），但 T 不是超码 → 违反 BCNF。

**Q5: 给出一个关系模式和其函数依赖集，判断其最高范式等级。**

> 典型考题模式：R(A,B,C,D)，F = {A→B, B→C, A→D}，候选码 A。非主属性 B,C,D 对 A 完全依赖 ✓(2NF)。但 A→B, B→C → C 传递依赖 A ✗(3NF)。最高为 2NF。

### BCNF 定义再精炼

> **定义 6.8**：R ∈ 1NF，若对任意 X → Y（Y ⊈ X），X 必含候选码，则 R ∈ BCNF。
>
> 等价表述：**所有非平凡函数依赖的决定因素都是超码。**
