## 一句话总结

Armstrong公理系统提供了**从已知函数依赖推导新函数依赖**的推理规则——通过属性闭包计算判断 X→Y 是否成立，通过最小覆盖求得等价的最精简依赖集，是模式分解算法的理论基础。

## 核心概念

### 1. Armstrong 公理的三条基本规则

| 规则 | 表达 | 含义 |
|------|------|------|
| **自反律** | 若 Y ⊆ X ⊆ U，则 X → Y | 超集必然决定子集（平凡依赖） |
| **增广律** | 若 X → Y，且 Z ⊆ U，则 XZ → YZ | 两边添加相同属性后依赖仍成立 |
| **传递律** | 若 X → Y 且 Y → Z，则 X → Z | 依赖可传递 |

Armstrong公理系统是**有效的**（推导出的依赖都成立）和**完备的**（所有蕴涵的依赖都能推导出）。

### 2. 三条扩充规则（由基本规则推导）

- **合并规则**：若 X → Y 且 X → Z，则 X → YZ
- **分解规则**：若 X → YZ，则 X → Y 且 X → Z
- **伪传递规则**：若 X → Y 且 WY → Z，则 XW → Z

### 3. 函数依赖集闭包与属性集闭包

**F⁺（F 的闭包）**：从函数依赖集 F 出发，用 Armstrong 公理推导出的**所有**函数依赖的集合。

**X⁺_F（属性集 X 关于 F 的闭包）**：在 F 下，由 X 能函数确定的**所有属性的集合**。

**核心引理 6.2**：X → Y 能由 Armstrong 公理从 F 推出，当且仅当 Y ⊆ X⁺_F。

→ 判断 X → Y 是否成立 = 计算 X⁺_F 然后检查 Y ⊆ X⁺_F。

### 4. 属性集闭包算法（算法 6.1）

```
输入：X, F
输出：X⁺_F
(1) X⁺ = X
(2) 重复扫描 F，对每个 Y → Z ∈ F：
    若 Y ⊆ X⁺，则 X⁺ = X⁺ ∪ Z
    直到 X⁺ 不再变化
(3) 输出 X⁺
```

**应用**：判断候选码——若 X⁺ = U（整个属性集），则 X 是超码；在此基础上检查"完全性"。

### 5. 最小覆盖（极小函数依赖集）

**定义 6.15**：F 满足以下条件时的等价依赖集 F_min：
1. 所有依赖的右部都是单属性
2. 去掉任何依赖或去掉依赖左部的任何属性，都不再与 F 等价

→ 最精简的依赖集，用于模式分解和规范化判断。

## 记忆卡片

**Q1: Armstrong 公理的三条基本规则？**
A1: 自反律（Y⊆X → X→Y）、增广律（X→Y → XZ→YZ）、传递律（X→Y & Y→Z → X→Z）。系统有效且完备。

**Q2: 如何判断 X→Y 是否成立？**
A2: 计算 X⁺，检查 Y ⊆ X⁺。是 → 成立；否 → 不成立。

**Q3: 属性闭包 X⁺ 的含义？**
A3: 从 X 出发能函数确定的所有属性的集合。是判断候选码和验证函数依赖的核心工具。

### 高频考点详解

**考点①：属性闭包计算（算法6.1）**
- 给 F 和 X，手工迭代算出 X⁺
- 陷阱：必须反复扫描直到 X⁺ 不再变化，不能只扫一轮
- 关联：是题型2-4的基础工具

**考点②：最小覆盖三步法（顺序不能乱）**
- Step 1：右部拆单属性
- Step 2：逐个删依赖，用闭包判断冗余
- Step 3：逐个减左边属性，用闭包判断冗余
- 陷阱：删除依赖时用当前 F 计算闭包，不是用原始 F

**考点③：候选码（L类+验证）**
- L 类（只左不右的属性）必须进候选码
- 算 L 的闭包，不够再加中间属性（LR类）
- 验证任何真子集闭包 ≠ U

**考点④：引理6.2**
- X→Y 能被推出 ⟺ Y ⊆ X⁺
- 等价表述：X→Y ∈ F⁺ ⟺ Y ⊆ X⁺_F
- 这是所有操作题的底层原理

**考点⑤：概念辨析**
- 自反律→平凡依赖（Y⊆X）；非平凡依赖（Y⊈X）；完全非平凡依赖（X∩Y=∅）
- F⁺ 是概念工具（指数级），X⁺ 是计算工具（线性级）
- 有效 = 推出的都对；完备 = 对的都能推出

## 简答题 Q&A

**Q4: 什么是"逻辑蕴涵"？和Armstrong公理推导的关系是什么？**
A4: 逻辑蕴涵是语义概念——F 中所有依赖在任意关系 r 上都成立时，X→Y 也必然成立。Armstrong 公理是语法工具——用三条规则机械推导。有效+完备确保两者等价：推得出 ⟺ 逻辑蕴涵。

**Q5: 求最小覆盖时，为什么"先删依赖，再减左部"顺序不能乱？**
A5: 因为先减左部可能改变依赖的结构，影响后续冗余依赖的判断。先删依赖时左部还是完整的，判断更准确。如果颠倒，可能得到一个不是最小的集合。

**Q6: 候选码和超码的区别是什么？**
A6: 超码的闭包 = U（能唯一标识元组）。候选码是最小的超码——它的任何真子集的闭包 ≠ U。

**Q7: F⁺ 和 F_min 的关系是什么？**
A7: F_min ⊆ F ⊆ F⁺，且 (F_min)⁺ = F⁺。F_min 是 F 的最精简等价版本，闭包能力完全相同，但依赖条数最少。用于模式分解算法以降低计算复杂度。

**Q8: 给定 F={A→C, B→D, AB→E}，求 {A,B}⁺**
A8: 初始 {A,B} → A→C 加入 C → {A,B,C} → B→D 加入 D → {A,B,C,D} → AB→E（A,B ⊆ {A,B,C,D} ✓）加入 E → {A,B,C,D,E}。最终 {A,B}⁺ = {A,B,C,D,E}。
