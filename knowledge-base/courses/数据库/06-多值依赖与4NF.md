## 一句话总结

BCNF 消除了函数依赖造成的异常，但无法解决**多值依赖**（一个属性独立地决定另一组属性的多个值）带来的冗余——**4NF** 就是针对这种场景，要求每个非平凡的多值依赖的决定因素都含候选码。

## 核心概念

### 1. 多值依赖（MVD）——超出函数依赖的范畴

**经典反例**：Teaching(C, T, B) — 课程、教师、参考书。一门课有多个教师和多本参考书，且教师和参考书的选择是**独立**的。

- 候选码：(C, T, B)，即全码
- **满足 BCNF**（因为没有非平凡的函数依赖，决定因素都是超码）
- 但仍然存在巨大的数据冗余——每增加一个教师，就要为该课程的所有参考书各插入一条记录

**多值依赖的形式化定义（定义 6.9）**：设 R(U)，X, Y, Z ⊆ U，Z = U − X − Y。若对于 R 的任何实例 r，给定 (x, z₁) 和 (x, z₂) ∈ r，则必有 (x, y₁, z₂) 和 (x, y₂, z₁) ∈ r。则称 **X 多值决定 Y**（或 Y 多值依赖于 X），记作 **X →→ Y**。

通俗理解：**X 的每个取值独立地对应 Y 的一组取值，Y 的取值与 Z 的取值无关**（对称性）。

### 2. 多值依赖的性质

- **对称性**：若 X →→ Y，Z = U − X − Y，则 X →→ Z
- **传递性**：若 X →→ Y 且 Y →→ Z，则 X →→ Z − Y
- 函数依赖是**多值依赖的特例**——当 Y 的取值集合都是单元素时

### 3. 4NF（第四范式）

**定义**：R ∈ 1NF，且对于 R 中的每一个**非平凡的多值依赖 X →→ Y（Y ⊈ X）**，X 都必须包含候选码。

4NF 消除了**非平凡且非函数依赖的多值依赖**。所有 4NF 的关系必然满足 BCNF，但反之不然。

Teaching(C, T, B) 中：C →→ T 且 C →→ B → 但 C 是部分码，不是超码 → 违反 4NF。解决：分解为 CT(C, T) 和 CB(C, B)。

## 难点突破

### 函数依赖 vs 多值依赖——什么时候需要多值依赖？

**判断方法**：当一个关系模式满足 BCNF 但仍存在冗余时，检查是否存在"两个独立的多值关系"。如果 X 的一个值对应 Y 的多个值，且 Y 的取值与 Z 无关——这就是多值依赖。

**Teaching 的例子**：一门课有 3 位老师和 4 本参考书 → 需要 12 行存储全部组合。即使满足 BCNF，冗余依然严重。因为教师和参考书是**独立**分配给课程的，它们之间没有依赖关系。

## 记忆卡片

**Q1: BCNF 和 4NF 的关系？**
A1: 4NF ⊆ BCNF。BCNF 只消除函数依赖异常，4NF 额外消除多值依赖异常。

**Q2: 多值依赖 X →→ Y 的直观含义？**
A2: X 的值独立地决定了一组 Y 值，Y 的取值与关系的其他属性（Z）无关。

**Q3: Teaching(C,T,B) 满足 BCNF 但为什么不满足 4NF？**
A3: C →→ T，但 C 不是超码（码是全码 (C,T,B)）→ 违反 4NF。且教师和参考书的笛卡尔积存储造成了不必要的冗余。

## 考点标注

- ⭐ **多值依赖的定义与直观理解**：X →→ Y 意味着 X 独立决定一组 Y，与 Z 无关。必须能用自己的话解释 Teaching(C,T,B) 为什么有 MVD
- ⭐ **MVD 的对称性**：X →→ Y ⇔ X →→ Z（Z = U−X−Y），一个 MVD 必然伴随另一个
- ⭐ **4NF 定义**：非平凡 MVD 的决定因素必含候选码
- ⭐ **BCNF vs 4NF**：BCNF 消除 FD 异常，4NF 额外消除 MVD 异常；4NF ⊆ BCNF
- **函数依赖是 MVD 特例**：Y 取值集合为单元素时退化

## 补充 Q&A

**Q4: Teaching(C,T,B) 满足 BCNF 却仍有冗余，根本原因是什么？**
A4: 候选码是全码 (C,T,B)，不存在非平凡函数依赖 → 满足 BCNF。但 C →→ T 和 C →→ B 是多值依赖，C 不是超码，教师和参考书独立组合产生笛卡尔积冗余（3教师×4参考书=12行）。

**Q5: 如何判断一个 MVD 是平凡的？**
A5: Y ⊆ X 或 X ∪ Y = U（即 Y 覆盖全部剩余属性）。只有非平凡的 MVD 才需要检查 4NF。

**Q6: 4NF 分解和 BCNF 分解有什么区别？**
A6: BCNF 分解按函数依赖违反复分解；4NF 分解按多值依赖违反复分解。Teaching 分解为 CT(C,T) 和 CB(C,B)，每张表中 C 都是码，各自满足 4NF。
