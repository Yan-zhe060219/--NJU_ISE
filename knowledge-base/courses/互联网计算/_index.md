# 互联网计算

## 课程概述
南京大学智能软件与工程学院，孟晴开老师授课。采用自顶向下方法（Kurose & Ross 教材体系），从应用层逐层向下讲解计算机网络。覆盖五层协议栈：应用层 → 运输层 → 网络层（数据平面+控制平面）→ 链路层（以太网、交换机、VLAN、MPLS、数据中心）→ 全栈综合。课程已全部处理完毕 ✅。

**核心主线**：因特网 = 分层架构 + 分组交换 + 逐层可靠通信。IP 是"细腰"，TCP 在不可靠的 IP 之上建立可靠字节流，应用层协议各司其职，路由协议让全网找到最优路径。

## 重要概念索引

### 贯穿全课程的核心概念
- **分层 (Layering)**：分解复杂性的核心思想，每层为上层提供服务
- **封装 (Encapsulation)**：每层加头部，形成 PDU（Message → Segment → Datagram → Frame）
- **尽力而为 vs 可靠通信**：IP 是尽力而为，TCP 在其上建立可靠字节流
- **复用/分解 (Mux/Demux)**：端口号区分应用进程
- **沙漏模型**：IP 是细腰，上面所有应用，下面所有链路技术

### 各层核心协议
| 层 | 协议 | 要点 |
|------|------|------|
| 应用层 | HTTP, DNS, SMTP, FTP | 定义消息格式和交互规则 |
| 运输层 | TCP, UDP | 进程间通信，可靠/不可靠 |
| 网络层 | IP, OSPF, BGP, ICMP, OpenFlow | 主机间通信，转发+路由，SDN |

### 关键算法
- **Dijkstra**（链路状态路由）：全局拓扑，贪心最短路径
- **Bellman-Ford**（距离向量路由）：分布式迭代，邻居交换 DV
- **AIMD**（拥塞控制）：加性增乘性减，唯一收敛到公平+效率
- **路径向量 (Path Vector)**（BGP）：AS-PATH + 策略，适合 AS 间路由
- **集中式控制平面**（SDN）：控制器统一下发流表，替代分布式协议计算

## 💬 学习对话补充

### 2026-05-18：英文课件 + 中文笔记的学习策略设计

**类型：** 关联

**背景：** 本课程课件全部为英文（Kurose & Ross 原版 PPT），而知识库笔记以中文为主。用户在学习开始前提出了一个关键问题：纯中文笔记在转换过程中可能丢失原文的精确含义——尤其计算机网络这种术语密集型学科，中文翻译常有多个版本（如 "datagram" 有人译数据报、有人译数据包），对照学习时容易产生混淆。用户想在保持中文阅读流畅性的前提下，确保笔记的准确性不偏离原意。

**讨论过程：** 最初提出了三种方案。方案一是"笔记末尾加关键原句板块"——从英文原文中摘 5-8 句最重要的定义性陈述，附中文翻译，让笔记自带双语对照，用户不用翻原文。方案二是"AI 做原文校验器"——学习过程中随时问"原文怎么说的"，AI 去读 .cache 英文原文给出对照。方案三是"修改笔记模板本身"——核心概念标题用 `English Term（中文翻译）` 格式，Mermaid 知识地图节点双语标注，每个笔记新增术语对照表和关键原句两个板块。

用户选择了方案三，并进一步提出要求：系统应能自动检测源材料语言，英文课件用双语增强模板，中文课件保持原有风格。这个判断很关键——不是所有课都需要同样的处理，数据库、软件工程这些中文教材课程如果也强制双语标注反而画蛇添足。

语言检测的实现基于对 inbox 下所有 .cache 文件的抽样：互联网计算和高级算法的课件中文占比 < 6%（纯英文 PPT），数据库和软件工程的课件中文占比 > 40%（中文教材）。双峰分布意味着一个简单的阈值（中文占比 > 10% → 中文源）就能完美区分所有课程，不需要复杂的 NLP 判断。

**核心收获：** 这次讨论的结果不只是改了一个模板，更重要的是确立了一个原则：**知识库笔记应该"以中文为主要阅读语言，但英文术语作为精度锚点嵌入"**。具体来说：

1. **术语一致性**：笔记中每个核心概念首次出现时标注英文原文（如 "传输控制协议（Transmission Control Protocol, TCP）"），消除了中译版本的歧义——以后看到任何中文翻译都能对应回标准英文术语。
2. **原句验证**：关键原句板块让每篇笔记自带"权威引用"——如果对某段中文解释存疑，直接看原文是怎么说的，不用翻 50 页英文 PPT。
3. **自动适配**：检测逻辑（中文占比 > 10%）在教学材料领域是可靠且极简的。课程课件不同于一般网页——它要么是纯英文（中国大陆以外的教材），要么是纯中文（中国大陆教材），几乎没有真正的双语混排课件。

**延伸思考：** 这个双语策略适用于所有使用英文原版教材的课程（如本学期的 高级算法）。对于未来新开的课程，只要课件拖入 inbox 后跑 `/learn`，系统会自动判断并选择对应模板，无需手动配置。如果遇到真正的双语混排课件（中英各半的 PPT），当前 10% 阈值仍会判定为中文源（因为中文已超过 10%），这种情况可以手动在笔记生成后追加术语对照——但目前看来这种课件几乎不存在。
