# 按目的使用的轻量模板

共享定义只在 [standards.md](standards.md)。模板按需要取用；用户问一个问题不必填满整张模板。

## 详细笔记

```markdown
---
title: 主题
goal: 目标ID
document_status: verified
sources:
  - material: 材料SHA256
    path: ../materials/原文件名.pdf
    location: PDF物理页3–5（印刷页1–3）
related: []
---

# 主题

从直观问题或例子引出本节，与前置知识建立联系。

## 原理与推导

按因果或逻辑顺序展开，解释符号、条件和术语，保留准确来源。

## 例子与边界

必要的演算或应用，类比的适用范围，容易混淆之处。

## 来源与关联

材料定位、补充来源、相邻笔记链接；个人错题仅链接记录。
```

document_status描述文档核实程度，不代表用户掌握程度。部分未核实不标verified，拆出pending或明确局部来源范围。

## 目的差异

| 用途 | 正文重点 | 简明地图入口 |
|---|---|---|
| 学校课程 | 章节逻辑、定义、例题、课程要求；只有有依据时标考试重点 | 章节/先修关系/重点/问题记录 |
| 论文 | 问题—方法—证据—局限—可迁移点；指标写比较对象、分母与百分点 | 论文身份、节/图表导航、待核实论点 |
| 自主学习/语言考试 | 学习目标、任务类型、方法、例子、错误原因；区分教材与模型建议 | 技能地图、题型、错题链接、复习入口 |

## 地图模板

```markdown
# 目标名称

## 知识导航
- [主题](notes/主题.md)：一句话说明它解决什么问题。

## 重点与前置
- 重点依据是什么；先读哪个主题。

## 疑问与薄弱点
- [问题/错题](records/事件ID.json)：简述尚未解决的困难。

## 复习入口
- 可选复习任务或笔记入口。能力和完成统计请读真实记录。
```
