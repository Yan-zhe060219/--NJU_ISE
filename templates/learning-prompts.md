# 学习场景 Prompt 模板

直接复制粘贴到 Claude Code 中使用。把 `[xxx]` 替换为实际内容。

---

## 1. 深度讲解一个概念

> 请用通俗的语言深入讲解 [概念名称]。
> 要求：
> - 先说它解决什么问题（为什么需要它）
> - 再讲核心思想和推导过程
> - 给出一个生活中的类比帮助理解
> - 最后列出 3 个关键记忆点
> - 不要用学术腔，目标读者是大一学生

## 2. 对比两个相似概念

> 请对比 [概念A] 和 [概念B]。
> 要求：
> - 分别一句话解释各自是什么
> - 用表格列出核心区别（至少 3 个维度）
> - 说明各自适用什么场景
> - 给出代码示例说明区别（如果适用）

## 3. 从 PDF 快速提取知识

> 阅读附件 PDF，帮我做以下事情：
> - 用 3 句话总结全文核心内容
> - 提取 5-10 个关键概念，每个用一句话解释
> - 画出概念之间的依赖关系（哪个概念是理解哪个概念的前置）
> - 标注我认为需要重点理解的 3 个难点
> - 把所有内容整理成知识库笔记格式，保存到 knowledge-base/

## 4. 视频讲座学习

> 这是 [课程名] 的讲座视频链接：[URL]
> 请获取视频内容（字幕/简介），然后：
> - 列出讲座的结构大纲
> - 每个部分的核心观点
> - 我不理解的地方（标注出来）
> - 生成知识库笔记，关联到已学内容

## 5. 费曼复习法

> 我想复习 [主题]。请充当我的"学生"，我会尝试用自己的话解释这个概念。
> 你要做的：
> - 听我解释后，指出哪里有漏洞或没说清楚的地方
> - 追问"为什么"来检验我的理解深度
> - 如果我说错了，纠正并给出正确的理解
> - 最后给出你这个"老师"版本的简洁解释

## 6. 建立知识图谱

> 请阅读 knowledge-base/ 下所有笔记的 frontmatter 和内容，
> 画出一张概念依赖图（用 Mermaid 格式），
> 标注哪些概念是其他概念的前置知识，
> 推荐一条最优的学习路径（先学什么，再学什么）。

## 7. 课程深度问答（使用 /study 命令）

> 推荐使用 `/study` 命令代替手动 prompt。它会自动加载课程上下文，结束时把洞察沉淀到笔记。

```
# 进入问答模式
/study start 操作系统

# 聚焦特定章节
/study start 操作系统 --chapter 4

# 像聊天一样提问，例如：
#   "上下文切换到底切换了什么？"
#   "为什么自旋锁在多核上才有意义？"
#   "能不能用生活中的例子解释死锁的四个条件？"

# 结束并保存
/study done
```

> `/study done` 时 AI 会自动：
> - 回顾对话中所有有价值的 Q&A
> - 还原每条洞察的思考脉络（背景→讨论过程→核心收获→延伸思考）
> - 用结构化多段落格式追加到对应章节笔记的"💬 学习对话补充"区域
> - 更新笔记状态（draft → reviewed）
