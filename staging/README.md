# staging

此目录用于存放尚未正式纳入课程目录的资料。

| 子目录 | 用途 | 移出条件 |
|---|---|---|
| unclassified/ | 无法确定课程归属的文件 | 确认课程后迁入 courses/ |
| ai-generated/ | AI 生成且未人工验证的资料 | 验证后迁入课程，错误则删除 |
| external-unmatched/ | 外部资料，暂未匹配课程 | 确认对应课程后迁入课程 |

规则：
1. staging 中的资料不视为正式课程资料。
2. 任何资料进入 courses/ 前必须确认课程归属和可信度。
3. AI 生成资料默认不可信。
