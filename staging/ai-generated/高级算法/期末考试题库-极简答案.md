## Q1: 低 ℓ∞-norm 对高斯 JL 变换没有帮助

**1.** Π ∈ ℝ^{m×d}，π_{ij} ~ N(0, 1/m) 独立。x ∈ S^{d-1}（‖x‖₂ = 1）。

(Πx)_i = Σ_{j=1}^d π_{ij} x_j

由正态分布可加性：Σ_j x_j · N(0, 1/m) ~ N(0, Σ_j x_j²/m) = **N(0, 1/m)**

各坐标独立，因为不同 i 的 π_{ij} 独立。

**2.** ‖Πx‖₂² = Σ_{i=1}^m (Πx)_i²。由 (1) 知 (Πx)_i ~ N(0, 1/m) i.i.d.。

令 Z_i = √m · (Πx)_i，则 Z_i ~ N(0, 1) i.i.d.。

‖Πx‖₂² = (1/m) Σ_{i=1}^m Z_i² **~ (1/m) χ²_m**

该分布仅依赖于 m，与 x 的具体坐标值无关，特别是与 ‖x‖∞ 无关。∎

**3.** 高斯 JL 的集中不等式：

P[|‖Πx‖₂² − 1| > ε] ≤ 2 exp(−mε²/8)

此上界仅含 m，与 x 的任何性质（包括 ‖x‖∞）无关。令其 ≤ δ 得 m ≥ (8/ε²) ln(2/δ) = **Θ(ε⁻² log(1/δ))**。即使 ‖x‖∞ ≤ O(1/√d)，m 仍为此量级。

**4.** **坐标采样**：直接输出 x 的某几维（缩放）。若 ‖x‖∞ 小（能量均匀分布），每维方差均匀 → 少量采样即可准确估计范数。

**高斯 JL**：每个输出坐标已是所有输入维的加权和，天然"均匀化"。无论原始 x 的 ‖x‖∞ 多大或多小，每个 (Πx)_i 的方差恒为 1/m。故低 ℓ∞-norm 不带来额外收益。

## Q2: Torus 上的随机网格 LSH

空间 ([0,n]^d, d_torus)，网格宽 w，随机平移 s ∈ [0,w)^d。Δ_i = min{|x_i−y_i|, n−|x_i−y_i|}。

**1.** 对所有 i 有 Δ_i < w 时（不会被 torus 边界影响）。

每坐标：网格线均匀分布在 [0,w) 上。x_i 和 y_i 之间的区间长度为 Δ_i，网格线落在此区间内的概率 = Δ_i/w。同桶 ⇔ 网格线不落入 → 概率 = 1 − Δ_i/w。各坐标独立 ∏，故

**P[h_s(x) = h_s(y)] = ∏_{i=1}^d (1 − Δ_i/w)**

**2.** 由 Cauchy-Schwarz：Σ Δ_i ≤ √d · √(Σ Δ_i²) = √d · d_torus(x,y) ≤ √d · r。

利用 ∏(1−a_i) ≥ 1 − Σ a_i（归纳法，a_i ≥ 0）：

∏(1−Δ_i/w) ≥ 1 − Σ Δ_i/w ≥ **1 − √d·r/w** ∎

**3.** 随机平移 s 使 axis-aligned cubes（边长 w）的位置在空间中均匀随机。近点 (r ≪ w)：各坐标差小 → 大概率落在同一 cube 中。远点：多坐标有显著差 → cube 边界容易将其切开。此即 LSH 的核心：P(近点碰撞) > P(远点碰撞)。

**4.** 高维局限：当 d_torus(x,y) 均匀分散在所有 d 个坐标上时，虽然总距离不大，但 (1−Δ_i/w) 的乘积 → 0（d 大时）。网格将距离"切碎"到各坐标上，每坐标贡献一个 <1 的因子，乘积指数衰减。

**5.** 仅一个坐标相差 r（r < w），其余全同：

**P = 1 − r/w**

**6.** 每坐标差 r/√d（r/√d < w），总 torus 距离 = r：

**P = (1 − r/(w√d))^d**

**7.** 同为 torus 距离 r：(5) P = 1−r/w vs (6) P = (1−r/(w√d))^d ≈ e^{−r√d/w}。由于 (1−x)^d 的凸性，即使总距离相同，**分散程度不同 → 碰撞概率不同**。

**8.** Axis-aligned grid LSH 不是仅依赖于欧氏距离的完美 LSH family。碰撞概率受坐标方向和各坐标上距离分布的影响：距离集中于少数坐标 → 好；均匀分散 → 高维灾难。

## Q3: 球面上的随机超平面 LSH

球面 S^{d-1}，d(x,y) = arccos⟨x,y⟩。h_g(x) = sign(g·x)，g ~ N(0, I_d)。

**1.** 对任意 x,y ∈ S^{d-1}，令 θ = arccos⟨x,y⟩。

g·x 和 g·y 是联合正态：均值为 0，方差为 1，协方差 Cov(g·x, g·y) = x^T E[gg^T] y = x^T I_d y = ⟨x,y⟩ = cos θ。

对于相关系数为 cos θ 的二元标准正态 (X,Y)，由球对称性或极坐标积分得 P[XY > 0] = 1 − θ/π。

即 **P[h_g(x) = h_g(y)] = 1 − θ/π** ∎

**2.** 随机向量 g 给出过原点的随机超平面，法向量为 g。h_g(x) = +1/−1 表示 x 在超平面的正/负侧。x 和 y 同侧 ⇔ 超平面不穿过它们之间的球面弧。弧长为 θ，超平面方向在球面上均匀分布 → 穿过该弧的概率 = θ/π，不穿过的概率 = 1 − θ/π。

**3.** k 个独立 g_i → k 个独立 hash 函数。组合 key H(x) = (h_{g₁}(x), ..., h_{g_k}(x))。

独立性 → **P[H(x)=H(y)] = (1 − θ/π)^k**

**4.** 近点 (d ≤ θ₁)：p₁ = 1 − θ₁/π。远点 (d ≥ θ₂)：p₂ = 1 − θ₂/π。

ρ = log(1/p₁)/log(1/p₂) = **log(1−θ₁/π) / log(1−θ₂/π)**

小角度近似 log(1−x) ≈ −x：ρ ≈ θ₁/θ₂。

## Q4: 由范数保持推出内积保持

**1.** 用极化恒等式：⟨x,y⟩ = (‖x+y‖² − ‖x−y‖²)/4。

同理 ⟨Πx,Πy⟩ = (‖Π(x+y)‖² − ‖Π(x−y)‖²)/4。

由范数保持条件：
- (1−ε)‖x+y‖² ≤ ‖Π(x+y)‖² ≤ (1+ε)‖x+y‖²
- (1−ε)‖x−y‖² ≤ ‖Π(x−y)‖² ≤ (1+ε)‖x−y‖²

代入得：
⟨Πx,Πy⟩ − ⟨x,y⟩ ≤ ε(‖x+y‖² + ‖x−y‖²)/4
⟨Πx,Πy⟩ − ⟨x,y⟩ ≥ −ε(‖x+y‖² + ‖x−y‖²)/4

由平行四边形法则 ‖x+y‖² + ‖x−y‖² = 2(‖x‖²+‖y‖²)：

**|⟨Πx,Πy⟩ − ⟨x,y⟩| ≤ (ε/2)(‖x‖²+‖y‖²) = O(ε)(‖x‖²+‖y‖²)** ∎

**2.** ‖x‖=‖y‖=1 时：**|⟨Πx,Πy⟩ − ⟨x,y⟩| ≤ ε = O(ε)**

**3.** JL 变换对 n 个点保证所有两两距离在 (1±ε) 内近似保持。将集合扩充为 {x_i} ∪ {x_i+x_j} ∪ {x_i−x_j}（O(n²) 个额外点），则 JL 对这些扩充点仍保持距离 → Π 对 {x, y, x+y, x−y} 保持范数 → 由 (1) 得内积保持。JL 目标维数仍为 O(ε⁻² log n)。

**4.** 在单位球面上 ‖x−y‖² = 2−2⟨x,y⟩ = 4sin²(θ/2)。JL 保持距离 → 保持 ‖x−y‖² → 保持 ⟨x,y⟩ = cos θ。由 arccos 在 (−1,1) 上的连续性及微商 |arccos'(t)| = 1/√(1−t²) = 1/sin θ：对不同角度范围给出不同精度保证。当 θ 不接近 0 或 π 时，内积误差 O(ε) 转换为角度误差 O(ε/sin θ)。

## Q5: 从阈值 ANN 到 Approximate Nearest Neighbor

**1.** 设真正最近邻距离为 d*。令 k = min{i : ∃p, ‖p−q‖ ≤ r_i}。由于 d* 是最小距离，d* > r_{k−1} 且 d* ≤ r_k = b·r_{k−1}。

黑盒在半径 r_{k−1} 时可能无返回。在半径 r_k 时，p* 满足 ‖p*−q‖ = d* ≤ r_k = b·r_{k−1}，黑盒返回 p' 满足：

‖p'−q‖ ≤ a·r_k = a·b·r_{k−1} **< a·b·d***

最终近似比 **≤ ab** ∎

**2.** 目标 c-近似 → 需 ab ≤ c。可取 **a = b = √c** → ab = c。

**3.** a = √c 时黑盒只需 √c-近似（< c），对黑盒要求更松；b = √c 使半径增长率温和，层级数 O(log_{√c} Δ) = O(log Δ / log c) 可控。

**4.** r₀ = 1，r_i = b^i。需 r_K ≥ Δ → b^K ≥ Δ → K ≥ log_b Δ。

**层级数 = ⌈log_b Δ⌉**。取 b = √c 时 K = O(log Δ / log c)。

## Q6: 先用 JL 降维，再做随机超平面 LSH

**1.** 已知对所有 x,y ∈ P：
- |‖Πx−Πy‖² − ‖x−y‖²| ≤ ε（距离保持）
- |‖Πx‖² − 1| ≤ ε（范数保持）

对集合 {x, y, x+y, x−y} 应用范数保持条件（注意 ‖x+y‖² 和 ‖x−y‖² 需要用距离保持和范数保持联合推出），由极化恒等式（见 Q4）得：

**|⟨Πx,Πy⟩ − ⟨x,y⟩| ≤ O(ε)**

**2.** θ = arccos⟨x,y⟩，θ̂ = arccos(⟨Πx,Πy⟩/(‖Πx‖·‖Πy‖))。

由 (1) 分子近似 ⟨x,y⟩ ± O(ε)。分母 ‖Πx‖·‖Πy‖ ∈ [1−ε, 1+ε] ≈ 1 ± O(ε)。

因此归一化内积 ≈ ⟨x,y⟩ ± O(ε)。由 arccos 微商 |arccos'(t)| = 1/√(1−t²)：

**|θ̂ − θ| ≤ O(ε / sin θ)**

当 θ 不接近 0 或 π 时 sin θ = Ω(1)，误差为 O(ε)。

**3.** JL 将维度从 d 降至 m = O(ε⁻² log n) ≪ d，在低维空间中运行随机超平面 LSH。碰撞概率 1−θ̂/π ≈ 1−(θ±O(ε))/π，只要 ε 远小于 θ，LSH 行为与原始空间几乎相同。时间复杂度从 O(d) 降为 O(m) 每 hash。

**4.** 当 θ 很小时 sin θ ≈ θ，误差 |θ̂−θ| ≤ O(ε/θ)。例如 θ=0.01，ε=0.01 → 误差可达 O(1)。要保证角度相对误差 ≤ 50%（即 |θ̂−θ| ≤ θ/2），需 O(ε/θ) ≤ θ/2 → **ε ≤ O(θ²)**。近点需要更小的 JL 误差 → 更大的 m。

## Q7: 为什么 CountSketch 需要随机符号

**1.** 无符号版本：Π_{h(i),i} = 1，x = (1,...,1)/√n。

令 B_k = #{i : h(i) = k} ~ Binomial(n, 1/m)。‖Πx‖² = (1/n) Σ_{k=1}^m B_k²。

E[B_k²] = Var(B_k) + E[B_k]² = n/m·(1−1/m) + n²/m²。

E[‖Πx‖²] = (1/n)·m·[n/m·(1−1/m) + n²/m²] = (1−1/m) + n/m = **1 + (n−1)/m** ∎

**2.** m = o(n) 时 E[‖Πx‖²] = 1 + (n−1)/m ≫ 1。而真实 ‖x‖² = 1。估计严重偏高。根本原因：不同 i 碰撞到同一桶时，都是 +1 相加，产生系统性正偏差。

**3.** 标准 CountSketch：Π_{h(i),i} = σ_i ∈ {±1}。桶 k 的值为 Σ_{i:h(i)=k} σ_i/√n。

其平方 = (1/n)(Σ σ_i² + Σ_{i≠j} σ_i σ_j) = (1/n)(B_k + Σ_{i≠j} σ_i σ_j)。

取期望：E[σ_i σ_j] = E[σ_i]E[σ_j] = 0（独立，均值 0）。交叉项期望全部为零，仅 σ_i² = 1 的项保留 → E[‖Πx‖²] = (1/n)·n = 1（无偏）。

**4.** 随机符号**不能避免碰撞**（两个 i 仍可能映射到同一桶），但使碰撞产生的交叉项 σ_i σ_j 的**期望为零**。碰撞误差从系统性偏差变为零均值的随机噪声，可通过增大 m 控制方差。

## Q8: CountSketch OSE 的 m = Ω(d²) 下界

设 Π 每列只有一个非零元，位置和值可任意确定。考虑随机矩阵 A：每列 j ∈ [d] 独立随机选一行 r_j ∈ [n]，A_{r_j, j} = 1，其余为 0。

考虑 ΠA 对单位向量 e_j ∈ ℝ^d 的作用。Ae_j = 第 r_j 个标准基向量，ΠAe_j = Π 的第 r_j 列（只有一行非零，记此行号为 h(r_j)）。

考察 ‖ΠA(e_i + e_j)‖²。若 h(r_i) ≠ h(r_j)，两个非零元在不同行 → 范数正确。若 h(r_i) = h(r_j)（碰撞），两列的非零元在同一行 → 范数估计出错（可能抵消或加倍，取决于 Π 的具体取值）。

为保证对 A 列空间的 OSE 成立，需对所有 i≠j 避免碰撞。

d 个独立随机行号 r_1,...,r_d 投入 m 个桶。无碰撞概率：

P[无碰撞] = ∏_{i=0}^{d-1} (1 − i/m) ≈ exp(−d²/(2m))

要此概率 ≥ 常数（如 1/2）→ d²/(2m) = O(1) → **m = Ω(d²)**。

若 m = o(d²)，以高概率存在碰撞 → 存在 e_i+e_j 使得范数估计错误 → Π 不是 OSE。故任何 column sparsity = 1 的矩阵做 OSE 必须 **m = Ω(d²)**。∎

## Q9: CountSketch OSE 的 m = O(d²/ε²δ) 上界

**1.** (Π^T Π)_{i,j} = Σ_{k=1}^m Π_{k,i} Π_{k,j}。

- i=j：仅 h(i) 行有非零元 σ_i，Π_{h(i),i}² = σ_i² = 1 → (Π^T Π − I_n)_{i,i} = 0。
- i≠j：仅当 h(i)=h(j) 时 Π_{h(i),i} Π_{h(j),j} = σ_i σ_j ≠ 0。

故 **(Π^T Π − I_n)_{i,j} = 1_{h(i)=h(j)} σ_i σ_j**（i≠j），对角元为 0。

**2.** U^T Π^T Π U − I_d = U^T (Π^T Π − I_n) U + U^T U − I_d = U^T (Π^T Π − I_n) U（因 U^T U = I_d）。

展开：= Σ_{i,j} (Π^T Π − I_n)_{i,j} · u_i u_j^T = **Σ_{i≠j: h(i)=h(j)} σ_i σ_j u_i u_j^T**

**3.** ‖Σ_{i≠j,碰撞} σ_i σ_j u_i u_j^T‖_F² 展开为双重和：

Σ_{i≠j,碰撞} Σ_{k≠ℓ,碰撞} σ_i σ_j σ_k σ_ℓ · tr(u_i u_j^T u_ℓ u_k^T)

取期望。σ_i 与 h(i) 独立，E[σ_i] = 0。若 {i,j} ≠ {k,ℓ}，四个 σ 中至少一个"独苗"，期望为零。仅当 {i,j} = {k,ℓ}（同一对自身相乘）时 E[σ_i² σ_j²] = 1 保留。

**4.** 保留的项：Σ_{i≠j} P[h(i)=h(j)] · ‖u_i u_j^T‖_F²。

P[h(i)=h(j)] = 1/m。‖u_i u_j^T‖_F² = tr(u_j u_i^T u_i u_j^T) = ‖u_i‖²‖u_j‖²（其中 u_i 为 d 维列向量）。

故 **E[‖U^T Π^T Π U − I_d‖_F²] = (1/m) Σ_{i≠j} ‖u_i‖² ‖u_j‖²** ≤ (1/m) Σ_{i≠j} ‖u_i‖² ‖u_j‖²。

**5.** Σ_i ‖u_i‖² = ‖U‖_F² = tr(U^T U) = tr(I_d) = d。

Σ_{i≠j} ‖u_i‖²‖u_j‖² ≤ (Σ_i ‖u_i‖²)² = d²。

故 **E[‖...‖_F²] ≤ d²/m**。

**6.** Markov 不等式：P[‖...‖_F > ε] = P[‖...‖_F² > ε²] ≤ E[‖...‖_F²]/ε² ≤ d²/(mε²) ≤ δ（当 m ≥ d²/(ε²δ)）。

即以概率 ≥ 1−δ，‖U^T Π^T Π U − I_d‖_F ≤ ε。

**7.** 对任意 x ∈ ℝ^d，令 y = Ux。则：

|‖ΠUx‖² − ‖Ux‖²| = |x^T (U^T Π^T Π U − I_d) x| ≤ ‖U^T Π^T Π U − I_d‖_op · ‖x‖²

而 ‖M‖_op ≤ ‖M‖_F（Frobenius 范数是谱范数的上界）。由 (6) ‖M‖_F ≤ ε → ‖M‖_op ≤ ε。

又 ‖Ux‖² = x^T U^T U x = ‖x‖²，故 **(1−ε)‖Ux‖² ≤ ‖ΠUx‖² ≤ (1+ε)‖Ux‖²**。

**8.** CountSketch 每列只有一个非零元（column sparsity = 1），但取 m = **O(d²/(ε²δ))** 即可作为 d 维子空间的 ε-OSE。结合 Q8 的下界 m = Ω(d²)，**m = Θ(d²) 是 column sparsity = 1 OSE 的紧界**。

## Q10: 点容量最大流

**建图（拆点法）**：

对每个 v ∈ V \ {s, t}：
- 拆为 v_in 和 v_out
- 加边 (v_in → v_out)，容量 = **c_v**

对原图每条边 (u, v)（若 u 或 v 为 s/t 则直接连接）：
- 加边 (u_out → v_in)，容量 = **∞**

s 保持为 s（或 s_out），t 保持为 t（或 t_in）。

**正确性**：

任何 s-t 流 f 中，流经 v 的总流量 = 经过 f(v_in → v_out) 的量。容量 c_v 限制此量，对应原问题的点容量约束。反之，新图的任何 s-t 流对应原图一个满足点容量约束的可行流（方向边无容量限制）。变换是一一对应且保流值。

**算法**：在新图上运行 Edmonds-Karp 或 Dinic。新图有 ≤ 2n 个点，≤ m+n 条边，均多项式规模 → 多项式时间。

## Q11: 二分图最大匹配与最小点覆盖的线性规划

**最大匹配 ILP**：

max Σ_{e∈E} x_e
s.t. Σ_{e∋v} x_e ≤ 1, ∀v ∈ V
     x_e ∈ {0, 1}, ∀e ∈ E

**LP 松弛**：将 x_e ∈ {0,1} 放松为 x_e ≥ 0。

**对偶 LP**（对每条约束 Σ_{e∋v} x_e ≤ 1 引入对偶变量 y_v ≥ 0）：

min Σ_{v∈V} y_v
s.t. y_u + y_v ≥ 1, ∀(u,v) ∈ E
     y_v ≥ 0, ∀v ∈ V

**最小点覆盖 ILP**：

min Σ_{v∈V} y_v
s.t. y_u + y_v ≥ 1, ∀(u,v) ∈ E
     y_v ∈ {0, 1}, ∀v ∈ V

其 LP 松弛恰好是对偶 LP。

**证明 ν(G) = τ(G)**：

(1) 二分图的关联矩阵是全单模的 → 匹配 LP 的基本可行解是整数 → LP* = ν(G)。

(2) 对偶 LP 的约束矩阵也是二分图关联矩阵的转置，同样全单模 → 对偶 LP* = τ(G)。

(3) 由线性规划的**强对偶性**：原始 LP* = 对偶 LP*。

因此 **ν(G) = τ(G)**（Kőnig 定理）。∎

## Q12: 背包问题的线性规划松弛与取整

**ILP**：

max Σ_{i=1}^n v_i x_i
s.t. Σ_{i=1}^n w_i x_i ≤ C
     x_i ∈ {0, 1}

**LP 松弛**：将 x_i ∈ {0,1} 放松为 0 ≤ x_i ≤ 1。

**取整算法**：

(1) 解 LP 得最优解 x*。
(2) 将物品按 v_i/w_i（性价比）降序排列。
(3) 按此顺序贪心选取物品：能装入背包容量的就选（x_i=1），直到下一个装不下。
(4) 记贪心解的总价值为 V_greedy。设 k 为第一个装不下的物品，v_k 为其价值。
(5) 输出 max(V_greedy, v_k)。

**近似比证明**：

OPT_LP = Σ v_i x*_i ≥ OPT（LP 是松弛，最优值更大）。

将 x* 中 k 及之前的物品的 LP 值加起来：贪心取到 k−1 的全部，第 k 个装不下。有：

V_greedy + v_k ≥ Σ_{i=1}^k v_i x*_i ≥ OPT_LP ≥ OPT

（前半部分 — 因为前 k−1 个物品的 LP 值被贪心全部取走，第 k 个物品的 LP 值不超过其自身价值 v_k）

故 **max(V_greedy, v_k) ≥ OPT/2**，1/2-近似。∎

## Q13: 带下界的可行流

**算法（归约标准最大流）**：

**Step 1**：对每条边 e = (u,v)，令新容量 c'_e = u_e − l_e（剩余容量），并强制边上有 l_e 的"预流"。

**Step 2**：计算每个点 v 的净需求：

d(v) = Σ_{e 入 v} l_e − Σ_{e 出 v} l_e

**Step 3**：构造新网络。在 G 的基础上（边容量为 c'_e），添加超级源 S* 和超级汇 T*：

- 若 d(v) > 0（该点净流入预流）→ 加边 (S*, v)，容量 = d(v)
- 若 d(v) < 0（该点净流出预流）→ 加边 (v, T*)，容量 = −d(v)

**Step 4**：在改造后的网络上求 S* 到 T* 的最大流 f'。

**判据**：存在满足下界的可行流 ⇔ **S* 的所有出边均被 f' 饱和**。

**可行流构造**：若是，原图可行流为 f_e = l_e + f'_e（预流 + 调整流）。

**正确性**：

下界预流 l_e 使各点产生流量不平衡 d(v)。f' 的作用恰是"校正"此不平衡：f' 流入 v 的量 − f' 流出 v 的量 = −d(v)，使得预流+调整后在每个点满足流量守恒。S* 出边饱和 ⇔ 所有净需求得到满足 ⇔ 存在可行调整 f'。∎

## Q14: DAG 最小路径覆盖

**归约二分图最大匹配**：

构造二分图 H = (L, R, E')：
- L = {ℓ_1, ..., ℓ_n}（每个原图顶点的"出发"副本）
- R = {r_1, ..., r_n}（每个原图顶点的"到达"副本）
- 对每条原边 (u,v) ∈ E：在 H 中添加边 (ℓ_u, r_v)

**求 H 的最大匹配**，设匹配大小为 M。

**最小路径覆盖大小 = |V| − M**。

**证明**：

将路径覆盖中的每条有向边 (u,v) 解释为"u 的下一跳是 v"。在 H 中，选边 (ℓ_u, r_v) ⇔ 在原路径中 u 直接连到 v。匹配条件保证：
- 每个 ℓ_u（出发）至多匹配一次（每个点至多有一条出边）
- 每个 r_v（到达）至多匹配一次（每个点至多有一条入边）

初始状态：每个点自成一条路径 = n 条路径。添加一条匹配边 (ℓ_u, r_v) → 将 u 所在路径片段和 v 所在路径片段拼接为一条 → 路径总数减 1。匹配是最大的 → 路径数 = n − M 是最小的。∎

## Q15: 点不相交路径

**归约最大流（拆点法）**：

对每个 v ∈ V \ {s, t}：
- 拆为 v_in 和 v_out
- 添加边 (v_in → v_out)，容量 = **1**

对每条原边 (u, v ∈ V \ {s,t})：
- 添加边 (u_out → v_in)，容量 = 1（或 ∞，因为点容量已限制）

对涉及 s 或 t 的边类似调整（s → v 变为 s → v_in；u → t 变为 u_out → t）。

**求 s 到 t 的最大流**，最大流值即为**最大内部点不相交 s-t 路径数**。

**证明（Menger 定理 - 点版本）**：

每个内部点 v 的边 (v_in → v_out) 容量为 1 → 至多一条单位流（一条路径）可以通过 v。流量 1 的单位流对应一条 s-t 路径（由边容量 1 保证路径不共边，由点容量 1 保证不共内部点）。最大流值 = 最大内部点不相交路径数 = 最小 s-t 点割大小（Menger 定理）。∎

## Q16: 带权点覆盖的 Primal-Dual 算法

**ILP**：

min Σ_{v∈V} w_v x_v
s.t. x_u + x_v ≥ 1, ∀(u,v) ∈ E
     x_v ∈ {0, 1}

**LP 松弛**：放松为 x_v ≥ 0。

**对偶 LP**：

max Σ_{e∈E} y_e
s.t. Σ_{e∋v} y_e ≤ w_v, ∀v ∈ V
     y_e ≥ 0, ∀e ∈ E

**Primal-Dual 算法**：

(1) 初始化：所有 y_e = 0，所有 x_v = 0。所有边"未覆盖"。
(2) WHILE 存在未覆盖边 (u,v)（x_u = x_v = 0）：
    持续增大 y_{uv} 直到存在端点 u 或 v 满足 Σ_{e∋u} y_e = w_u（或对 v 类似）。
    将满足条件的端点选入覆盖（x_v = 1），其所有邻边标为"已覆盖"。
(3) 返回选中的点集 C = {v : x_v = 1}。

**近似比 = 2 的证明**：

**对偶可行**：算法始终维护 Σ_{e∋v} y_e ≤ w_v（一旦某个 v 达到 w_v 就选入覆盖，不再参与后续边的提价），因此 y 是对偶可行解。

**覆盖权重 ≤ 2·对偶目标值**：

Σ_{v∈C} w_v = Σ_{v∈C} Σ_{e∋v} y_e（因为 v 被选中时约束恰好变紧）

上述二重和中，每条边 e = (u,v) 的 y_e 最多被其两个端点各计一次（若两端点均被选中则计两次，若仅一端被选中则计一次）≤ 2·y_e。

故 Σ_{v∈C} w_v ≤ 2 Σ_{e∈E} y_e。

**推出近似比**：由弱对偶性，Σ_e y_e ≤ OPT_LP ≤ OPT。因此

Σ_{v∈C} w_v ≤ 2·Σ_e y_e ≤ 2·OPT。

**近似比 = 2**。∎

## Q17: Set Cover 的线性规划松弛与随机取整

**ILP**：

min Σ_{S∈𝒮} c_S x_S
s.t. Σ_{S∋e} x_S ≥ 1, ∀e ∈ U
     x_S ∈ {0, 1}

**LP 松弛**：放松为 x_S ≥ 0。记 LP 最优解为 x*_S。

**随机取整算法**：

令 α > 0。对每个 S ∈ 𝒮，独立地以概率

x'_S = min{1, α·x*_S}

选择集合 S。输出所有被选中的集合。

**分析**：

(1) 覆盖概率：对任意元素 e ∈ U，

P[e 未被任何选中集合覆盖] = ∏_{S∋e} (1 − x'_S)
≤ ∏_{S∋e} exp(−α x*_S)（因 1−z ≤ e^{−z}）
= exp(−α Σ_{S∋e} x*_S) ≤ exp(−α)（因 LP 约束 Σ_{S∋e} x*_S ≥ 1）

取 α = c·ln|U|（c > 1）：P[e 未被覆盖] ≤ |U|^{−c}。

由 Union Bound：P[∃e 未被覆盖] ≤ |U|·|U|^{−c} = |U|^{1−c} → 0（当 |U|→∞ 且 c>1）。

故以高概率，所有元素被覆盖。

(2) 期望成本：

E[总成本] = Σ_S c_S · x'_S ≤ α Σ_S c_S x*_S = α·OPT_LP ≤ α·OPT

取 α = Θ(log|U|) → 期望成本 = O(log|U|)·OPT。

**该算法为 O(log|U|)-近似**。∎

## Q18: 带点容量和需求的最小费用运输问题

**建图**：

构造有向流网络，节点包括：

- 超级源 S、超级汇 T
- 每个工厂 i：节点 F_i
- 每个仓库 v：拆为 W_v^{in} 和 W_v^{out}，中间加边 (W_v^{in} → W_v^{out})，容量 = **c_v**，费用 = 0
- 每个商店 j：节点 R_j

**边及其参数**：

1. (S → F_i)：容量 = s_i（工厂供应上限），费用 = 0
2. (F_i → W_v^{in})：容量 = 对应运输边的 u_e（或 ∞），费用 = a_e
3. (W_v^{in} → W_v^{out})：容量 = c_v（仓库吞吐上限），费用 = 0
4. (W_v^{out} → R_j)：容量 = 对应运输边的 u_e（或 ∞），费用 = a_e
5. (R_j → T)：容量 = d_j（商店需求），费用 = 0

工厂间直达、仓库间转运等边可类似添加。

**求解**：

在新网络上求 **S 到 T 的最小费用最大流**（如 Successive Shortest Path 算法）。

**判据**：最大流值 = Σ_j d_j → 存在满足所有需求的运输方案；此时的最小费用即为最优总运输成本。

**正确性**：

- S→F_i 边容量 s_i 保证工厂 i 总发货量 ≤ s_i
- W_v 拆点 + 容量 c_v 保证经仓库 v 的总流量 ≤ c_v
- R_j→T 边容量 d_j 且必须饱和 → 每个商店恰好收到 d_j
- 边费用如实反映运输成本，目标函数 min Σ a_e f_e 即总运输成本
- 流量守恒保证中间节点的货物"进出平衡"，对应物理上的货物不凭空产生/消失

**因此模型与原问题等价**。∎
