一、低 \ell_\infty-norm 对高斯 JL 变换没有帮助

令 \Pi \in \mathbb{R}^{m \times d} 是一个高斯 Johnson-Lindenstrauss 变换，其中每个元素独立服从 \mathcal{N}(0, 1/m)。给定任意固定单位向量 x \in S^{d-1}。
1. 证明 \Pi x 的每个坐标都独立服从 \mathcal{N}(0, 1/m)。
2. 证明 \|\Pi x\|_2^2 与 \frac{1}{m} \chi_m^2 同分布。因此 \|\Pi x\|_2^2 的分布与 \|x\|_\infty 无关。
3. 解释为什么如果使用高斯 JL 变换，即使 x 满足很强的平坦性条件，例如 \|x\|_\infty \leq O(1/\sqrt{d})，为了保证 \mathbb{P}[\|\Pi x\|_2^2 - 1| > \epsilon] \leq \delta，所需的目标维数仍然是 m = \Theta(\epsilon^{-2}\log(1/\delta))。
4. 对比坐标采样型（即 \Pi x 直接随机输出 x 的某几个维度）降维，简要解释为什么低 \ell_\infty-norm 对坐标采样有帮助，但对高斯 JL 变换没有帮助。

二、torus 上的随机网格 LSH

考虑 metric space ([0, n]^d, d_{\text{torus}})，其中距离定义为 d_{\text{torus}}(x, y) = \sqrt{\sum_{i=1}^d \min\{|x_i - y_i|, n - |x_i - y_i|\}^2}。给定网格宽度 w > 0，随机选择平移向量 s \in [0, w)^d，并定义 hash 函数 h_s(x) = (\lfloor (x_1 + s_1)/w \rfloor, \dots, \lfloor (x_d + s_d)/w \rfloor)，其中每个坐标都按照 torus 的方式取模。
1. 对于两个点 x, y \in [0, n]^d，记 \Delta_i = \min\{|x_i - y_i|, n - |x_i - y_i|\}。证明如果对所有 i 都有 \Delta_i < w，那么 \mathbb{P}[h_s(x) = h_s(y)] = \prod_{i=1}^d (1 - \Delta_i/w)。
2. 证明如果 d_{\text{torus}}(x, y) \leq r，那么 \mathbb{P}[h_s(x) = h_s(y)] \geq 1 - \sqrt{d} \cdot r/w。提示：可以使用 \sum_i \Delta_i \leq \sqrt{d} \sqrt{\sum_i \Delta_i^2}。
3. 解释为什么这个 LSH family 的随机桶可以看成随机平移后的 axis-aligned cube。请从“近点容易落在同一个随机集合中，远点不容易落在同一个随机集合中”的角度解释这个构造的直觉。
4. 讨论这个构造在高维空间中的局限性。特别地，当距离 d_{\text{torus}}(x, y) 分散在很多个坐标上时，为什么随机网格更容易把 x 和 y 切开？
5. 设 x, y 只在一个坐标上相差 r，其他坐标完全相同。计算 \mathbb{P}[h_s(x) = h_s(y)]。
6. 设 x, y 在每个坐标上都相差 r/\sqrt{d}，因此 d_{\text{torus}}(x, y) = r。在 r/\sqrt{d} < w 的条件下，计算 \mathbb{P}[h_s(x) = h_s(y)]，并将其写成 (1 - r/(w\sqrt{d}))^d 的形式。
7. 比较上述两种情况。说明即使两对点的 torus 距离都等于 r，随机网格 LSH 的碰撞概率仍然可能不同。
8. 解释这说明了什么：axis-aligned grid LSH 并不是只依赖于欧氏距离的完美 LSH family，而是会受到坐标方向和维数的影响。

三、球面上的随机超平面 LSH

考虑球面空间 (S^{d-1}, d)，其中距离定义为 d(x, y) = \arccos(x, y)。随机选择 g \sim \mathcal{N}(0, I_d)，并定义 hash 函数 h_g(x) = \text{sign}(g \cdot x)。
1. 对任意 x, y \in S^{d-1}，令 \theta = \arccos(x, y)。证明 \mathbb{P}[h_g(x) = h_g(y)] = 1 - \theta/\pi。
2. 解释上述公式的几何直觉：随机超平面什么时候会把 x 和 y 分到两侧？
3. 现在使用 k 个独立随机超平面 g_1, \dots, g_k，并定义组合 hash key 为 H(x) = (h_{g_1}(x), \dots, h_{g_k}(x))。证明 \mathbb{P}[H(x) = H(y)] = (1 - \theta/\pi)^k。
4. 给定两个角度阈值 0 < \theta_1 < \theta_2 < \pi，令近点满足 d(x, y) \leq \theta_1，远点满足 d(x, y) \geq \theta_2。写出这个 LSH family 的参数 p_1 和 p_2，并推导标准 LSH exponent \rho = \log(p_1)/\log(1/p_2)。

四、由范数保持推出内积保持

设线性映射 \Pi 对向量集合 x, y, x + y, x - y 都保持平方范数，即对所有 v \in \{x, y, x + y, x - y\} 都有 (1 - \epsilon)\|v\|_2^2 \leq \|\Pi v\|_2^2 \leq (1 + \epsilon)\|v\|_2^2。
1. 使用恒等式 \langle x, y \rangle = (\|x + y\|_2^2 - \|x - y\|_2^2)/4，证明 |\langle \Pi x, \Pi y \rangle - \langle x, y \rangle| \leq O(\epsilon)(\|x\|_2^2 + \|y\|_2^2)。
2. 在 \|x\|_2 = \|y\|_2 = 1 的情况下，将上式化简为 |\langle \Pi x, \Pi y \rangle - \langle x, y \rangle| \leq O(\epsilon)。
3. 解释为什么如果 JL 变换对 n 个点的所有两两距离都近似保持，那么这些点的两两内积也近似保持。
4. 进一步讨论：如果这些点都在单位球面上，那么 JL 降维之后，球面角度 \arccos(x, y) 在什么意义下也被近似保持？

五、从阈值版 Approximate Near Neighbor 到 Approximate Nearest Neighbor

假设你有一个阈值版 Approximate Near Neighbor 黑盒。给定半径 r 和查询点 q，如果数据集 P 中存在点 p 满足 \|p - q\| \leq r，那么黑盒会返回某个点 p'，并保证 \|p' - q\| \leq ar。
现在希望用这个黑盒解决普通 Approximate Nearest Neighbor 问题。设真正最近邻距离为 d^* = \min_{p \in P} \|p - q\|。我们建立一组半径 r_0, r_1, r_2, \dots，满足 r_{i+1} = br_i。查询时，从小到大尝试这些半径，并返回第一个成功的黑盒查询结果。
1. 证明最终得到的近似比至多为 ab。
2. 如果希望最终得到 c-approximate nearest neighbor，应该如何选择 a 和 b？
3. 解释为什么常见做法中，会把阈值版 ANN 黑盒的近似比 a 从 c 设置为 \sqrt{c}。
4. 如果最近邻距离的可能范围被限制在 [1, \Delta] 中，分析需要建立多少个半径层级。

六、先用 JL 降维，再做随机超平面 LSH

设 P \subseteq S^{d-1} 是 n 个单位向量。令 \Pi : \mathbb{R}^d \rightarrow \mathbb{R}^m 是一个 JL 变换，并假设对所有 x, y \in P，都有 \|\Pi x - \Pi y\|_2^2 - \|x - y\|_2^2| \leq \epsilon。同时假设对所有 x \in P，都有 \|\Pi x\|_2^2 - 1| \leq \epsilon。
1. 证明对所有 x, y \in P，都有 |\langle \Pi x, \Pi y \rangle - \langle x, y \rangle| \leq O(\epsilon)。
2. 令 \theta = \arccos(x, y)，并令 \hat{\theta} = \arccos(\langle \Pi x, \Pi y \rangle / (\|\Pi x\|_2 \|\Pi y\|_2))。在 \theta 不太接近 0 或 \pi 的情况下，给出 |\theta - \hat{\theta}| 的上界。
3. 解释为什么可以先对数据集 P 做 JL 降维，再在低维空间中使用随机超平面 LSH。
4. 讨论当两个点的夹角非常小时，为什么需要更小的 JL 误差才能保证角度的相对误差较好。

七、为什么 CountSketch 需要随机符号

考虑一个没有随机符号的 CountSketch。对每个 i \in [n]，随机选择桶 h(i) \in [m]，并令 \Pi_{h(i), i} = 1，其他位置为 0。取向量 x = (1, 1, \dots, 1)/\sqrt{n}。
1. 证明 \mathbb{E}[\|\Pi x\|_2^2] = 1 + (n - 1)/m。
2. 说明如果 m = o(n)，那么这个没有随机符号的 sketch 对该向量的范数估计会有严重偏差。
3. 现在考虑标准的 CountSketch：对每个 i \in [n]，随机选择桶 h(i) \in [m]，并随机选择符号 \sigma_i \in \{-1, 1\}，令 \Pi_{h(i), i} = \sigma_i，其他位置为 0。解释随机符号 \sigma_i 如何使不同坐标碰撞产生的交叉项在期望中相互抵消。
4. 总结随机符号在 CountSketch 中的作用：它并不能避免碰撞，但可以让碰撞带来的误差成为均值为零的随机噪声。

八、CountSketch OSE 的 m = \Omega(d^2) 下界

假设 n \gg d（不妨假设 n > 2^d）。考虑使用一个 column sparsity 只有 1（即，每一列只有一个非零元素）的矩阵 \Pi \in \mathbb{R}^{m \times n} 进行 Oblivious Subspace Embedding (OSE)。考虑这样的随机矩阵 A \in \{0, 1\}^{n \times d}：A 的每一列随机选择一个位置为 1，其他位置为 0。尝试证明，任意确定的 \Pi 为 A 的列空间进行子空间嵌入都至少需要 m = \Omega(d^2)，即它作为 OSE 不可能降维到 o(d^2)。提示：尝试观察 \Pi A e_i, \Pi A(e_i + e_j) 的 \ell_2-norm，以及你可能需要应用 birthday paradox（随机地把 d 个球丢入 m 个桶中，那么要满足 m = \Omega(d^2) 才能使得有 \Omega(1) 的概率，这 d 个球中不会有两个球被丢进了同一个桶中）。

九、CountSketch OSE 的 m = O(d^2/\epsilon^2) 上界

令 U \in \mathbb{R}^{n \times d} 是一个列正交矩阵，即 U^\top U = I_d。令 \Pi \in \mathbb{R}^{m \times n} 是 CountSketch 矩阵：对每个原始坐标 i \in [n]，随机选择桶 h(i) \in [m]，并随机选择符号 \sigma_i \in \{-1, 1\}；然后令 \Pi_{h(i), i} = \sigma_i，其他位置为 0。记 u_i 为 U 的第 i 行，视为 \mathbb{R}^d 中的列向量。
1. 证明 \Pi^\top \Pi - I_n 的 (i, j) 个元素在 i \neq j 时等于 \mathbf{1}_{h(i) = h(j)} \sigma_i \sigma_j，在 i = j 时等于 0。
2. 推出 U^\top \Pi^\top \Pi U - I_d = \sum_{i \neq j: h(i) = h(j)} \sigma_i \sigma_j u_i u_j^\top。
3. 证明在计算 \mathbb{E}[\|U^\top \Pi^\top \Pi U - I_d\|_F^2] 时，随机符号会使所有交叉项的期望为 0。也就是说，只有同一对 (i, j) 与自身相乘的项会保留下来。
4. 证明 \mathbb{E}[\|U^\top \Pi^\top \Pi U - I_d\|_F^2] \leq \frac{1}{m} \sum_{i \neq j} \|u_i\|_2^2 \|u_j\|_2^2。
5. 使用 \sum_i \|u_i\|_2^2 = \|U\|_F^2 = d，证明 \mathbb{E}[\|U^\top \Pi^\top \Pi U - I_d\|_F^2] \leq d^2/m。
6. 用 Markov 不等式证明，如果 m \geq d^2/(\epsilon^2 \delta)，那么以概率至少 1 - \delta，有 \|U^\top \Pi^\top \Pi U - I_d\|_F \leq \epsilon。
7. 证明如果 \|U^\top \Pi^\top \Pi U - I_d\|_F \leq \epsilon，那么对所有 x \in \mathbb{R}^d 都有 (1 - \epsilon)\|Ux\|_2^2 \leq \|\Pi Ux\|_2^2 \leq (1 + \epsilon)\|Ux\|_2^2。并解释为什么第 (6) 问中的 Frobenius 范数 bound 足以推出 spectral norm bound。
8. 总结：说明 CountSketch 虽然每一列只有一个非零元素，但当 m = O(d^2/(\epsilon^2 \delta)) 时，仍然可以作为一个 d 维子空间的 Oblivious Subspace Embedding。
