## 一句话总结

**函数依赖是规范化理论的数学基础**——定义了属性间的决定关系（X→Y），并据此形式化定义了候选码（完全函数决定所有属性）、部分依赖、传递依赖等概念，为后续范式判断提供精确工具。

## 核心概念

### 1. 函数依赖（Functional Dependency）

**定义 6.1**：设 R(U) 是一个属性集上的关系模式，X, Y ⊆ U。若对于 R 的任意一个可能的关系 r，r 中不存在两个元组在 X 上相等而在 Y 上不等，则称 **X 函数确定 Y**，或 **Y 函数依赖于 X**，记作 **X → Y**。

通俗：**知道 X 的值就能唯一确定 Y 的值**。

- X 称为决定因素（Determinant）
- 若 X → Y 且 Y → X，记作 X ↔ Y
- 若 Y 不函数依赖于 X，记作 X ↛ Y

### 2. 平凡 vs 非平凡函数依赖

- **平凡函数依赖**：Y ⊆ X，如 (Sno, Sname) → Sname（必然成立）
- **非平凡函数依赖**：Y ⊈ X，如 Sno → Sdept（有实际约束意义）

规范化理论关注的是非平凡函数依赖。

### 3. 完全函数依赖 vs 部分函数依赖

**完全函数依赖（定义 6.2）**：若 X → Y，且对于 X 的任何真子集 X' 都有 X' ↛ Y，则称 Y **完全函数依赖**于 X，记作 ![](https://latex.codecogs.com/svg.image?X\overset{F}{\rightarrow}Y)。

**部分函数依赖**：若 X → Y，但存在 X 的真子集 X' 使得 X' → Y，则称 Y **部分函数依赖**于 X，记作 ![](https://latex.codecogs.com/svg.image?X\overset{P}{\rightarrow}Y)。

**这是判断 2NF 的关键概念**：2NF 要求非主属性对候选码必须是完全函数依赖（不能部分依赖）。

### 4. 传递函数依赖

**定义 6.3**：若 X → Y (Y ⊈ X)，Y ↛ X，Y → Z，则称 Z **传递函数依赖**于 X。

**这是判断 3NF 的关键概念**：3NF 要求非主属性不能有对候选码的传递函数依赖。

### 5. 基于函数依赖重新定义候选码

**定义 6.4**：设 K ⊆ U，若 K → U（K 完全函数确定所有属性），则 K 是 R 的**候选码**。

- **超码**：能函数确定 U 但可能不满足"完全"条件
- **全码**：整个属性组才是候选码
- **主属性**：包含在任何候选码中的属性
- **非主属性/非码属性**：不包含在任何候选码中的属性

**定义 6.5（外码）**：属性组 F 不是 R 的码，但 F 对应另一关系的主码。

## 难点突破

### 完全依赖 vs 部分依赖——最易混淆的判断

判断流程：(Sno, Cno) → Grade 是完全依赖吗？
1. 去掉 Sno：Cno → Grade？（假——仅靠课程号无法确定成绩）✗
2. 去掉 Cno：Sno → Grade？（假——仅靠学号无法确定成绩）✗
3. 没有任何真子集能独立确定 Grade → **完全函数依赖** ✓

而 (Sno, Cno) → Sdept：去掉 Cno → Sno → Sdept（真！）→ **部分函数依赖**。

### 简答题（期末笔试模拟）

**Q1: 写出函数依赖 X → Y 的形式化定义，并举例说明。**

> 参考答案：设 R(U)，X, Y ⊆ U。若对于 R 的任意一个可能的关系 r，r 中不存在两个元组在 X 上相等而在 Y 上不等，则称 X → Y。通俗：知道 X 的值就能唯一确定 Y 的值。例：Sno → Sname（学号决定了姓名），但 Sname → Sno 不一定成立（可能有同名）。若 X → Y 且 Y → X，记作 X ↔ Y（一一对应）。

**Q2: 什么是完全函数依赖和部分函数依赖？各举一例。**

> 参考答案：完全函数依赖 X→Y：X 的任何真子集都不能独立确定 Y。例：(Sno, Cno)→Grade 是完全依赖——仅凭 Sno 不能确定 Grade（学生有多个成绩），仅凭 Cno 也不能（一门课有多个学生）。部分函数依赖 X→Y：存在 X 的某真子集也能确定 Y。例：(Sno, Cno)→Sdept 是部分依赖——去掉 Cno，仅凭 Sno 已经能确定 Sdept。这是判断 2NF 的核心概念。

**Q3: 什么是传递函数依赖？举例说明。**

> 参考答案：若 X → Y（Y ⊈ X），Y ↛ X（Y 不决定 X），Y → Z，则 Z 传递函数依赖于 X。例：Sno → Sdept（学号决定系别），Sdept ↛ Sno（反过来不成立——一个系有多个学生），Sdept → Sloc（系别决定系的住处），因此 Sloc 传递函数依赖于 Sno。判断 3NF 的核心概念——3NF 要求消除非主属性的传递依赖。

**Q4: 基于函数依赖如何形式化定义候选码？超码、候选码、全码的区别？**

> 参考答案：候选码 K ⊆ U 满足：① K → U（能函数确定所有属性）；② K 的任何真子集都不能函数确定 U（满足完全性）。超码只需满足①，不要求②（可以有冗余属性）。全码是所有属性的集合才是候选码（没有任何属性组能完全确定 U）。主属性 = 包含在任意候选码中的属性，非主属性 = 不包含在任何候选码中。

**Q5: (Sno, Cno) → Grade 和 (Sno, Cno) → Sdept 分别是什么函数依赖？为什么一个是完全的、一个是部分的？**

> 参考答案：(Sno, Cno)→Grade 是完全函数依赖：去掉 Sno → Cno↛Grade（仅靠课程号无法确定一个学生的成绩）；去掉 Cno → Sno↛Grade（仅靠学号无法确定某一门课的成绩）；两子集均不能独立决定 Grade → 完全。(Sno, Cno)→Sdept 是部分函数依赖：去掉 Cno → Sno→Sdept（仅靠学号即可确定系别）→ 存在真子集 Sno 能独立决定 Sdept → 部分。前者的决定因素没有冗余，后者有。

## 记忆卡片

**Q1: 函数依赖 X → Y 的含义？**
A1: X 值相同时 Y 值必然相同。即 X 的取值决定了 Y 的取值。

**Q2: 完全函数依赖 vs 部分函数依赖？**
A2: 完全 = X 的所有真子集都不能独立确定 Y；部分 = 存在 X 的某个真子集也能确定 Y。判断 2NF 的核心！

**Q3: 什么是传递函数依赖？**
A3: X → Y（Y ⊈ X），Y → Z，且 Y ↛ X。判断 3NF 的核心！
