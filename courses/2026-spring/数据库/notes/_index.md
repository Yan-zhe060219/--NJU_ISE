# 数据库

## 课程概述

本课程系统讲解数据库系统的核心理论和技术。从数据库基本概念出发，深入关系数据模型，掌握 SQL 语言，理解数据库安全性与完整性机制，重点攻克关系数据库规范化理论（函数依赖→范式→Armstrong公理→模式分解→多值依赖/4NF），最后学习数据库编程技术（嵌入式SQL、存储过程、ODBC/JDBC）。课程以关系数据库为核心，理论与实践并重。

## 重要概念索引

### 核心概念（按主题）

**基础概念**：数据、数据库(DB)、数据库管理系统(DBMS)、数据库系统(DBS)、数据独立性

**数据模型**：概念模型、逻辑模型、物理模型、E-R模型、关系模型、三级模式二级映像

**关系理论**：域、笛卡尔积、关系、候选码、主码、外码、实体完整性、参照完整性

**关系代数**：选择(σ)、投影(π)、并(∪)、差(−)、笛卡尔积(×)、自然连接(⋈)、除(÷)

**SQL**：DDL(CREATE/ALTER/DROP)、DML(INSERT/UPDATE/DELETE)、SELECT、GROUP BY/HAVING、嵌套查询

**事务**：ACID（原子性/一致性/隔离性/持久性）、COMMIT、ROLLBACK

**安全性**：DAC（自主存取控制）、MAC（强制存取控制）、GRANT/REVOKE

**完整性**：实体完整性、参照完整性、用户定义完整性、断言(ASSERTION)、触发器(TRIGGER)

**规范化**：1NF→2NF→3NF→BCNF→4NF、函数依赖、多值依赖、Armstrong公理、模式分解
