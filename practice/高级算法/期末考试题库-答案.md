## Q1: 低 ℓ∞-norm 对高斯 JL 变换没有帮助

### 📖 详细版

令 **Π ∈ ℝ^{m×d}**，每个元素独立服从 **N(0, 1/m)**。x ∈ S^{d-1}（单位向量）。

#### 1. Πx 每个坐标的分布

**(Πx)_i = Σ_{j=1}^d π_{ij} x_j**

由正态分布可加性：π_{ij} ~ N(0, 1/m) 独立，x_j 固定 →
- **E[(Πx)_i] = 0**
- **Var[(Πx)_i] = Σ x_j² · (1/m) = ‖x‖₂²/m = 1/m**

∴ **(Πx)_i ~ N(0, 1/m)**，各坐标独立。✅

#### 2. ‖Πx‖₂² 的分布

‖Πx‖₂² = Σ_{i=1}^m (Πx)_i²

令 Z_i = √m · (Πx)_i ~ N(0, 1) i.i.d.，则：

**‖Πx‖₂² = (1/m) · Σ_{i=1}^m Z_i² ~ (1/m) · χ²_m**

> 📌 分布**仅依赖于 m**，与 x 的具体方向/‖x‖∞ 完全无关。

#### 3. 目标维数不变的根源

JL 误差来自 χ² 集中不等式：

**P[|‖Πx‖₂² − 1| > ε] ≤ 2 exp(−mε²/8)**

要此概率 ≤ δ → **m ≥ (8/ε²) ln(2/δ) = Θ(ε⁻² log(1/δ))**

> 📌 这个 bound **只含 m，不含 ‖x‖∞**。无论 x 多平坦，维数需求不变。

#### 4. 两种降维对比

| | 坐标采样 | 高斯 JL |
|---|---|---|
| 机制 | 随机输出 x 的某几维 | 所有维加权求和 |
| 每坐标方差 | 取决于 x_i²（不均匀） | **始终 1/m**（均匀） |
| ‖x‖∞ 小有帮助？ | ✅ 平坦→方差均匀→少样本 | ❌ 高斯已天然混合 |

> 📌 **核心**：高斯 JL 的每个投影坐标 = 所有 d 维的加权和 → 天然平坦化 → 不需要输入先平坦。

---

### 📋 极简背诵版

1. **(Πx)_i** = Σ_j π_{ij} x_j，正态可加性 → **N(0, 1/m)**，独立
2. **‖Πx‖₂²** = (1/m) Σ Z_i² **~ (1/m)χ²_m**，与 x（含 ‖x‖∞）无关
3. χ² 集中不等式 → **m = Θ(ε⁻² log(1/δ))**，不受 ‖x‖∞ 影响
4. 坐标采样：平坦 x → 方差小 → 少样本够；**高斯 JL：天然混合所有维度 → 平坦无益**

> **速记**：高斯投影 = 天然平均机，输入平坦不占便宜。m 只取决于 ε 和 δ。

## Q2: Torus 上的随机网格 LSH

### 📖 详细版

空间 ([0,n]^d, d_torus)，网格宽 w，随机平移 s ∈ [0,w)^d。
**h_s(x) = (⌊(x₁+s₁)/w⌋, ..., ⌊(x_d+s_d)/w⌋)**，坐标 torus 取模。
Δ_i = min{|x_i−y_i|, n−|x_i−y_i|}。

#### 1. 碰撞概率（所有 Δ_i < w）

每坐标独立：
- 网格线落在 x_i 和 y_i 之间的概率 = **Δ_i / w**
- 同一桶概率 = **1 − Δ_i/w**

∴ **P[h_s(x) = h_s(y)] = ∏_{i=1}^d (1 − Δ_i/w)**

#### 2. 下界（d_torus ≤ r）

Σ_i Δ_i ≤ √d · √(Σ_i Δ_i²) ≤ **√d · r**（Cauchy-Schwarz）

∏(1 − Δ_i/w) ≥ 1 − Σ Δ_i/w ≥ **1 − √d·r/w**

> 📌 第一不等式因 ∏(1−a_i) ≥ 1−Σa_i（a_i ≥ 0）。

#### 3. 几何直觉

随机网格 = 随机放置的 **axis-aligned cubes**（边长 w）。
- 近点 (r ≪ w)：各坐标靠得近 → **大概率同 cube**
- 远点：多坐标有显著差异 → **边界切开**

#### 4. 高维局限性

距离分散在多坐标上时，即使总欧氏距离小，碰撞概率也极低。

例：每坐标差 r/√d → P = (1 − r/(w√d))^d → 0（d 大时）
**高维网格把近点"切碎"**。

#### 5. 🔧 单坐标差异（已按 Wiki 原文修正）

x, y 只在**一个坐标**上相差 r（r < w），其他完全相同：

**P[h_s(x) = h_s(y)] = 1 − r/w**

> 只有这一个坐标可能被网格线分开，概率 = 1 − (网格线落在区间内的概率)。

#### 6. 所有坐标均匀分散

每坐标差 r/√d（r/√d < w）：

**P[h_s(x) = h_s(y)] = (1 − r/(w√d))^d**

#### 7. 碰撞概率不同

同为 torus 距离 r：
- 一坐标集中：P = **1 − r/w**（较高）
- 所有坐标均分：P ≈ **exp(−r√d/w)**（d 大时指数级小）

> 📌 函数 (1−x)^d 的凸性导致：即使总距离相同，**分散程度不同 → 碰撞概率不同**。

#### 8. 结论

> 📌 **Axis-aligned grid LSH 不单纯依赖欧氏距离**，受坐标方向和维数影响。距离集中少数坐标 → 好；距离分散多坐标 → 高维灾难。

---

### 📋 极简背诵版

1. 每坐标：P[同桶] = **1 − Δ_i/w** → 各坐标独立乘 → **∏(1−Δ_i/w)**
2. Cauchy-Schwarz → ∏ ≥ **1 − √d·r/w**
3. 直觉：随机平移 cube，近点易同 cube，远点被边界切开
4. 高维问题：距离分散多坐标 → P → 0（指数衰减）
5. 🔧 **单坐标差 r**：P = **1 − r/w**
6. **每坐标均分 r/√d**：P = **(1 − r/(w√d))^d**
7. 同等距离 → 分散度不同 → 碰撞概率不同（不是仅取决于欧氏距离的完美 LSH）

> **速记**：网格 LSH = ∏(1−Δ_i/w)；距离集中→好，分散→高维灾难。非纯距离 LSH。

## Q3: 球面上的随机超平面 LSH

### 📖 详细版

球面 S^{d-1}，d(x,y) = arccos(⟨x,y⟩)。**h_g(x) = sign(g·x)**，g ~ N(0, I_d)。

#### 1. 碰撞概率

g·x 和 g·y 是联合正态：均值 0，方差 1，相关系数 ρ = ⟨x,y⟩ = cos θ。

对二元标准正态 (X,Y) 相关系数 ρ：**P[XY > 0] = 1 − arccos(ρ)/π**。

∴ **P[h_g(x) = h_g(y)] = 1 − θ/π**

> 📌 这是球面上**最美的 LSH**：仅依赖角度 θ，与维数 d 无关！

#### 2. 几何直觉

g 定义随机超平面（法向量为 g）。
- h_g(x)=+1：x 在正侧；h_g(x)=−1：x 在负侧
- x,y 同侧 ⇔ 超平面**不穿过**它们之间的球面弧
- 弧长 = θ，超平面方向均匀 → 穿过概率 = θ/π

**θ 越小**（越近）→ 越难被切开 → **碰撞概率越大** ✓

#### 3. k 个独立超平面

H(x) = (h_{g₁}(x), ..., h_{g_k}(x))

独立 → **P[H(x)=H(y)] = (1 − θ/π)^k**

#### 4. LSH 参数 ρ

- 近点 (≤ θ₁)：**p₁ = 1 − θ₁/π**
- 远点 (≥ θ₂)：**p₂ = 1 − θ₂/π**
- **ρ = log(p₁)/log(p₂) = log(1−θ₁/π) / log(1−θ₂/π)**

小角度近似：log(1−x) ≈ −x → **ρ ≈ θ₁/θ₂**

---

### 📋 极简背诵版

1. **P[碰撞] = 1 − θ/π**（θ = arccos⟨x,y⟩），仅依赖角度，与维数无关
2. 几何：随机超平面方向均匀，穿过弧长 θ 的概率 = θ/π
3. k 个独立超平面：**P = (1 − θ/π)^k**
4. **ρ = log(1−θ₁/π)/log(1−θ₂/π) ≈ θ₁/θ₂**（小角度）

> **速记**：超平面 LSH：碰撞 = 1−θ/π。最美的距离无关维度的 LSH。k 个 → k 次方。

## Q4: 由范数保持推出内积保持

### 📖 详细版

Π 对 v ∈ {x, y, x+y, x−y} 都保持平方范数：**(1−ε)‖v‖² ≤ ‖Πv‖² ≤ (1+ε)‖v‖²**。

#### 1. 极化恒等式推导

⟨x, y⟩ = **(‖x+y‖² − ‖x−y‖²) / 4**（极化恒等式）

同样 ⟨Πx, Πy⟩ = (‖Π(x+y)‖² − ‖Π(x−y)‖²) / 4。

代入范数保持：
- ‖Π(x+y)‖² ∈ [(1−ε)‖x+y‖², (1+ε)‖x+y‖²]
- ‖Π(x−y)‖² ∈ [(1−ε)‖x−y‖², (1+ε)‖x−y‖²]

得：|⟨Πx,Πy⟩ − ⟨x,y⟩| ≤ **(ε/2)(‖x+y‖² + ‖x−y‖²) / 2**

由平行四边形法则 ‖x+y‖² + ‖x−y‖² = 2(‖x‖²+‖y‖²)：

∴ **|⟨Πx,Πy⟩ − ⟨x,y⟩| ≤ (ε/2)(‖x‖² + ‖y‖²) = O(ε)(‖x‖²+‖y‖²)**

#### 2. 单位向量

‖x‖ = ‖y‖ = 1 → **|⟨Πx,Πy⟩ − ⟨x,y⟩| ≤ ε = O(ε)**

#### 3. JL 保持距离 → 保持内积

JL 保持所有两两距离 + 引入 x_i+x_j 和 x_i−x_j 作为额外点 → 范数保持条件满足 → 极化恒等式 → 内积保持。需 O(n²) 个额外点，JL 维度仍为 O(ε⁻² log n)。

#### 4. 球面角度保持

在单位球面上：‖x−y‖² = 2−2⟨x,y⟩ = 4sin²(θ/2)。JL 保持距离 → 保持内积 → 保持 cos θ。

arccos 在 (−1,1) 连续：**|θ̂ − θ| ≤ O(ε/sin θ)**（微商 arccos'(t) = −1/√(1−t²)）。

> 📌 θ 接近 0（点很近）时 sin θ ≈ θ 很小 → 角度误差被放大。

---

### 📋 极简背诵版

1. **极化恒等式**：⟨x,y⟩ = (‖x+y‖² − ‖x−y‖²)/4
2. 范数保持 ±ε → 代入展开 → **|⟨Πx,Πy⟩−⟨x,y⟩| ≤ (ε/2)(‖x‖²+‖y‖²)**
3. 单位向量：**|内积误差| ≤ ε**
4. JL 保持距离 + 额外点(x+y, x−y) → 极化 → 内积保持 → 角度保持
5. 角度误差：**|θ̂−θ| ≤ O(ε/sin θ)**，θ 小时误差放大

> **速记**：范数保持 + 极化恒等式 = 内积保持。加 x±y 额外点即可。

## Q5: 从阈值 ANN 到 Approximate Nearest Neighbor

### 📖 详细版

**黑盒**：给定 r,q，若 ∃p: ‖p−q‖ ≤ r，返回 p' 满足 ‖p'−q‖ ≤ a·r。
**半径序列**：r_{i+1} = b·r_i，从小到大试，返回第一个成功结果。

#### 1. 近似比 ≤ ab

最近邻距离 d*。启动半径 r_k < d* ≤ r_{k+1} = b·r_k。

r_k 可能失败（无点满足 ‖p−q‖ ≤ r_k）。
r_{k+1} 时 d* ≤ r_{k+1} → 黑盒返回 p' 满足 **‖p'−q‖ ≤ a·r_{k+1} = a·b·r_k < a·b·d***。

∴ **近似比 ≤ ab**。

#### 2. 选择 a 和 b

要 c-近似：需 **ab ≤ c**。
- 常见：**a = b = √c** → ab = c（均分负担）

#### 3. 为什么 a = √c

- 黑盒近似比 √c < c → **对黑盒要求更松**（更容易实现）
- b = √c 不太大 → **层级数可控**
- 两边的代价均分

#### 4. 半径层级数

r₀ = 1, r_k = b^k ≥ Δ → k ≥ **log_b Δ = log Δ / log b**

b = √c 时：**k = O(log Δ / log c)**。c=2, Δ=poly(n)：k = O(log n)。

---

### 📋 极简背诵版

1. 半径序列 r_{i+1}=b·r_i，d* ∈ (r_k, b·r_k] → 返回 p' ≤ a·b·r_k < **a·b·d*** → 近似比 **ab**
2. 目标 c-近似：取 **a = b = √c**
3. a=√c：黑盒更松（√c < c），层级数可控
4. 层级数 = **⌈log_b Δ⌉ = O(log Δ / log b)**

> **速记**：几何级数半径 × 黑盒 → 总近似比 ab。选 a=b=√c 得 c-近似。

## Q6: 先用 JL 降维，再做随机超平面 LSH

### 📖 详细版

P ⊆ S^{d-1}（n 个单位向量）。Π: ℝ^d → ℝ^m 是 JL 变换。
假设：∀x,y ∈ P, **|‖Πx−Πy‖² − ‖x−y‖²| ≤ ε** 且 **|‖Πx‖² − 1| ≤ ε**。

#### 1. 内积保持

由 Q4 结论直接推出：**|⟨Πx,Πy⟩ − ⟨x,y⟩| ≤ O(ε)**

#### 2. 角度误差

θ = arccos⟨x,y⟩，θ̂ = arccos(⟨Πx,Πy⟩/(‖Πx‖·‖Πy‖))。

‖Πx‖ ≈ 1±ε/2，归一化内积 ≈ ⟨x,y⟩ ± O(ε)。

微商 arccos'(t) = −1/√(1−t²) = −1/sin θ：

**|θ̂ − θ| ≤ O(ε / sin θ)**

> 📌 当 θ 远离 0,π 时，sin θ 不小，误差可控。

#### 3. JL + LSH 的合理性

- JL 将 d → m = O(ε⁻² log n)，**m ≪ d**
- 降维后点在"近似球面"上 → 超平面 LSH 近似有效
- 碰撞概率 = 1−θ̂/π ≈ 1−(θ±O(ε))/π，**ε 小时与原始几乎相同**

#### 4. 小夹角的困难

θ 很小时 sin θ ≈ θ → |θ̂−θ| ≤ O(ε/θ)。

例：θ=0.01, ε=0.01 → 误差 O(1)！要使相对误差 ≤ 50%：需 **ε ≤ O(θ²)**。

> 📌 LSH 最关心的近点（θ 小），恰是 JL 保持角度最差的区域 → **需要更精确的 JL（更大 m）**。

---

### 📋 极简背诵版

1. JL 保持距离+范数 → 极化恒等式 → **内积误差 O(ε)**
2. 角度误差：**|θ̂−θ| ≤ O(ε/sin θ)**
3. 先 JL 降维 → 低维空间超平面 LSH → 降时间复杂度
4. **θ 小时 sin θ ≈ θ** → 误差 O(ε/θ) 放大 → 需更精确 JL (更大 m)

> **速记**：JL→超平面 LSH：误差 O(ε/sinθ)。近点 θ 小 → ε 要更小 → m 要更大。

## Q7: 为什么 CountSketch 需要随机符号

### 📖 详细版

**无符号版本**：每 i 随机选桶 h(i) ∈ [m]，Π_{h(i),i} = 1。取 x = (1,...,1)/√n。

#### 1. E[‖Πx‖²] 的计算

B_k = #{i : h(i)=k} ~ Binomial(n, 1/m)，Σ B_k = n。

‖Πx‖² = Σ_k (B_k/√n)² = (1/n) Σ B_k²

E[B_k²] = n/m · (1−1/m) + n²/m²

∴ **E[‖Πx‖²] = 1 + (n−1)/m**

#### 2. 偏差分析

m = o(n) → E[‖Πx‖²] → ∞ 或 ≫ 1。真实 ‖x‖² = 1 → **严重偏高**！

> 📌 根源：不同坐标碰撞到同一桶时，值相加（都是正），产生**系统性正偏差**。

#### 3. 随机符号如何抵消

标准版：Π_{h(i),i} = **σ_i ∈ {±1}**。

(Πx 的第 k 分量)² = (Σ_{i:h(i)=k} σ_i x_i)² = Σ σ_i²x_i² + **Σ_{i≠j} σ_i σ_j x_i x_j**

**E[σ_i σ_j] = E[σ_i]E[σ_j] = 0**（独立，均值 0）

∴ E[‖Πx‖²] = ‖x‖² = 1。**无偏！**

#### 4. 总结

| | 无符号 | 有符号 |
|---|---|---|
| 碰撞效果 | 正偏差（系统性偏高） | **零均值噪声** |
| 期望 | 1+(n−1)/m（有偏） | 1（无偏） |
| 方差控制 | 无法消除偏差 | 增大 m 即可控制方差 |

> 📌 随机符号**不避免碰撞**，但让碰撞误差变为**均值为 0 的随机噪声** → 增大 m 即可压制。

---

### 📋 极简背诵版

1. 无符号：E[‖Πx‖²] = **1 + (n−1)/m**，m=o(n) 时严重偏高
2. 根因：碰撞 = 正数相加 → 系统性正偏差
3. 随机符号：E[σ_i σ_j] = 0 → **交叉项期望抵消** → E[‖Πx‖²] = 1（无偏）
4. 符号不能避免碰撞，但让误差变**零均值噪声** → 增大 m 控制方差

> **速记**：无符号 = 有偏估计；±1 随机符号 → 碰撞项期望为零 → 无偏。符号 = 去偏差魔法。

## Q8: CountSketch OSE 的 m = Ω(d²) 下界

### 📖 详细版

**设定**：Π ∈ ℝ^{m×n}，每列只有一个非零元（column sparsity = 1）。
随机矩阵 A ∈ {0,1}^{n×d}：每列随机选一个位置放 1。
证明任意确定的 Π 为 A 的列空间做 OSE 需 m = Ω(d²)。

#### 证明思路

**核心**：利用生日悖论。

1. A 每列在 n 行中随机选一行放 1 → 产生 d 个随机位置
2. Π 每列只有一个非零元 → 它只能"采样"不能"混合"
3. 如果两列 i,j 的随机位置 h(r_i) = h(r_j)（碰撞），ΠA(e_i+e_j) 的范数估计出错
4. **生日悖论**：d 个球丢入 m 个桶，无碰撞概率：
   **P[无碰撞] = ∏_{i=0}^{d-1} (1−i/m) ≈ exp(−d²/(2m))**

5. 要 P[无碰撞] ≥ Ω(1)，需 **d²/(2m) = O(1) → m = Ω(d²)**

> 📌 **结论**：column sparsity = 1 的矩阵做 OSE，**根本下界 m = Ω(d²)**。这是紧的（Q9 给出上界）。

---

### 📋 极简背诵版

1. 单列稀疏 Π + 随机矩阵 A → Π 只能采样不能混合
2. A 的 d 列产生 d 个随机行位置 → 映射到 m 行
3. 两列碰撞 → 范数估计出错 → 必须避免碰撞
4. **生日悖论**：P[无碰撞] ≈ exp(−d²/(2m)) → 需 **m = Ω(d²)**

> **速记**：单列稀疏 + OSE → 必须避免列碰撞 → 生日悖论 → m ≥ Ω(d²)。

## Q9: CountSketch OSE 的 m = O(d²/ε²δ) 上界

### 📖 详细版

**设定**：U ∈ ℝ^{n×d}，U^T U = I_d（列正交）。Π 是 CountSketch：h(i) ∈ [m]，σ_i ∈ {±1}，Π_{h(i),i} = σ_i。
**u_i** = U 的第 i 行（ℝ^d 列向量）。

#### 1. Π^T Π − I_n 的元素

(Π^T Π)_{i,j} = Σ_k Π_{k,i} Π_{k,j}

- i=j：**= σ_i² = 1** → (Π^T Π − I_n) 对角元 = **0**
- i≠j：**= 1_{h(i)=h(j)} · σ_i σ_j**

#### 2. 展开

**U^T Π^T Π U − I_d = U^T (Π^T Π − I_n) U = Σ_{i≠j: h(i)=h(j)} σ_i σ_j u_i u_j^T**

#### 3. Frobenius 期望：交叉项抵消

展开 Frobenius 平方 → 交叉项含 σ_i σ_j σ_k σ_ℓ。

- {i,j} ≠ {k,ℓ} → 存在一个 σ 独苗 → **E = 0**
- 只有 **{i,j} = {k,ℓ}**（同一对与自身）→ E[σ_i²σ_j²] = 1 保留

#### 4. 上界

E[‖...‖_F²] = Σ_{i≠j} P[h(i)=h(j)] · ‖u_i u_j^T‖_F² = **(1/m) Σ_{i≠j} ‖u_i‖² ‖u_j‖²**

#### 5. 利用 U 的正交性

Σ_i ‖u_i‖² = ‖U‖_F² = tr(U^T U) = d

Σ_{i≠j} ‖u_i‖²‖u_j‖² ≤ (Σ_i ‖u_i‖²)² = **d²**

∴ **E[‖...‖_F²] ≤ d²/m**

#### 6. Markov 不等式

P[‖...‖_F > ε] ≤ E[‖...‖_F²] / ε² ≤ **d²/(m ε²)**

要 ≤ δ → **m ≥ d²/(ε²δ)**

#### 7. Frobenius → Spectral

需要证 Frobenius 范数 bound → spectral norm bound → OSE 性质。

**关键**：‖M‖_op ≤ ‖M‖_F（Frobenius 范数 ≥ 谱范数）。

若 ‖M‖_F ≤ ε → ‖M‖_op ≤ ε → ∀x: |‖ΠUx‖² − ‖Ux‖²| ≤ ε‖x‖²。

#### 8. 总结

CountSketch 每列只有**一个**非零元，但取 m = **O(d²/(ε²δ))** 即可作为 d 维子空间的 ε-OSE。

> 📌 上界 O(d²/ε²) + 下界 Ω(d²) → **m = Θ(d²) 是 column sparsity = 1 的紧界**。

---

### 📋 极简背诵版

1. Π^T Π−I_n：对角=0，非对角=**1_{h(i)=h(j)} σ_i σ_j**
2. **U^T Π^T Π U − I_d = Σ_{i≠j, 碰撞} σ_i σ_j u_i u_j^T**
3. 期望展开：只有 **{i,j}={k,ℓ}**（自身对）保留（随机符号消去其他交叉项）
4. **E[‖·‖_F²] ≤ (1/m) Σ_{i≠j} ‖u_i‖²‖u_j‖² ≤ d²/m**
5. Markov → m ≥ **d²/(ε²δ)** 时，P[‖·‖_F ≤ ε] ≥ 1−δ
6. ‖·‖_op ≤ ‖·‖_F → Frobenius bound ⇒ OSE 性质
7. 结论：**m = Θ(d²)** 是 column sparsity=1 OSE 的紧界

> **速记**：CountSketch OSE = 展开→期望(d²/m)→Markov→m=O(d²/ε²δ)。紧界 Θ(d²)。

## Q10: 点容量最大流

### 📖 详细版

**问题**：边容量 ∞，点 v 有容量 c_v。求 s-t 最大流。

#### 建图（拆点法）

对每个 **v ∈ V \ {s,t}**：
1. 拆为 **v_in** 和 **v_out**
2. 加边 **(v_in → v_out)**，容量 = **c_v**
3. 原边 (u,v) → **(u_out → v_in)**，容量 = **∞**

源 s 直接用 s_out，汇 t 直接用 t_in。

#### 正确性

- 流经 v 的总流量 = 经过 (v_in→v_out) 的流量 ≤ **c_v** ✓
- 新图 = 标准流网络 → **Edmonds-Karp / Dinic** 求最大流
- 原图流 ↔ 新图流：f'(v_in→v_out) = Σ_u f(u,v)

#### 复杂度

新图：2n−2 个点，m+n 条边。Dinic：O(V²E) = **O(n²m)**，多项式。

---

### 📋 极简背诵版

**建图**：每点 v 拆 v_in→v_out（容量 c_v），原边 (u,v) → (u_out→v_in) 容量 ∞。
**算法**：Dinic 求 s_out→t_in 最大流。
**正确性**：任何流经 v 的流量必须过 (v_in→v_out) ≤ c_v。

> **速记**：点容量 → 拆点（in→out=c_v）→ 标准最大流。

## Q11: 二分图最大匹配与最小点覆盖的 LP

### 📖 详细版

G = (L, R, E)。

#### 最大匹配 ILP → LP

**ILP**：max Σ_e x_e, s.t. Σ_{e∋v} x_e ≤ 1, x_e ∈ {0,1}
**LP 松弛**：同上，x_e ≥ 0（去掉整数约束）

#### 对偶 LP

对每条边约束配对偶变量 y_v：

**min Σ_v y_v**, s.t. **y_u + y_v ≥ 1** ∀(u,v) ∈ E, **y_v ≥ 0**

#### 最小点覆盖 ILP

**min Σ_v y_v**, s.t. y_u + y_v ≥ 1, y_v ∈ {0,1}

> 📌 最小点覆盖 LP 松弛 = 最大匹配 LP 的**对偶**！

#### ν(G) = τ(G) 的证明

1. 二分图关联矩阵 → **全单模** → 匹配 LP 最优解是整数 → LP* = ν(G)
2. 同理对偶 LP 最优解也是整数 → LP* = τ(G)
3. **强对偶性**：原始 LP* = 对偶 LP*

∴ **ν(G) = τ(G)**（Kőnig 定理）✅

---

### 📋 极简背诵版

- 最大匹配 ILP：max Σx_e, Σ_{e∋v}x_e ≤ 1, x_e∈{0,1}
- LP 对偶：min Σy_v, **y_u+y_v ≥ 1**, y_v ≥ 0
- 最小点覆盖 LP 松弛 = 上述对偶
- **证明**：二分图全单模 → LP 整数最优 → 强对偶性 → **ν(G)=τ(G)**

> **速记**：匹配 LP ↔ 点覆盖 LP 互为对偶 + 二分图全单模 → ν=τ（Kőnig）。

## Q12: 背包问题的 LP 松弛与取整

### 📖 详细版

**ILP**：max Σ v_i x_i, s.t. Σ w_i x_i ≤ C, x_i ∈ {0,1}
**LP**：同上，0 ≤ x_i ≤ 1

#### 取整算法（1/2-近似）

1. 解 LP 得 x*

设 OPT_LP ≥ OPT。k = 第一个装不下的物品。

贪心价值 V_greedy + v_k ≥ OPT_LP ≥ OPT

∴ **max(V_greedy, v_k) ≥ OPT/2** → **1/2-近似** ✅

- 算法：性价比排序贪心 + 比较最贵单品
- 证明：V_greedy + v_k ≥ OPT → max ≥ OPT/2
- **1/2-近似**（更好的用 DP → FPTAS）

> **速记**：背包 LP → 性价比贪心 + 最贵单品兜底 → 1/2-近似。

## Q13: 带下界的可行流

### 📖 详细版

**问题**：每条边 e 有 l_e ≤ f_e ≤ u_e，判断是否存在可行流。

#### 算法（归约标准最大流）

**Step 1**：改造网络
- 每边容量改为 **u_e − l_e**（可用容量）
- 强制预流 l_e

**Step 2**：超级源汇

每点净需求：**d(v) = Σ_{入} l_e − Σ_{出} l_e**

- d(v) > 0（净流入）→ 加边 **(v → T)**，容量 = d(v)
- d(v) < 0（净流出）→ 加边 **(S → v)**，容量 = −d(v)

**Step 3**：求 S→T 最大流

**判据**：存在可行流 ⇔ **S 的所有出边饱和**。

#### 可行流构造

若最大流饱和所有 S 出边：**f_e = l_e + f'_e**

---

### 📋 极简背诵版

1. 预流 l_e，剩余容量 u_e−l_e
2. 算每点净需求 d(v) = Σ入 l_e − Σ出 l_e
3. d(v)>0 → (v→T, cap=d(v))；d(v)<0 → (S→v, cap=−d(v))
4. 求 S→T 最大流 → **S 出边全饱和 ⇔ 可行**
5. 可行流 = l_e + f'_e

> **速记**：下界 → 预流 l_e → 算净需求 → 超级源汇 → S 出边饱和 = 可行。

## Q14: DAG 最小路径覆盖

### 📖 详细版

**问题**：DAG G=(V,E)，用最少顶点不相交路径覆盖所有点。

#### 归约二分图最大匹配

构造二分图 H = (L, R, E')：
- L = {v₁,...,v_n}（出发副本）
- R = {v₁',...,v_n'}（到达副本）
- ∀(u,v) ∈ E：加边 **(u, v')**

#### 定理

**最小路径覆盖大小 = |V| − M**（M = H 的最大匹配大小）

#### 证明

- 每匹配边 (u,v') ⇔ 原图 u 后紧跟 v
- 初始每个点自成路径 = n 条
- 每匹配一条边 → **减少一条路径**（两段合并）
- ∴ 路径数 = **n − M**

**算法**：Dinic / 匈牙利算法，O(n²m) / O(nm)。

---

### 📋 极简背诵版

- 构造二分图：L=出副本，R=入副本，(u,v)∈E → (u,v')∈二分图
- 最大匹配 M → **最小路径覆盖 = n − M**
- 理由：每匹配边减少一条路径（合并两段）

> **速记**：DAG → 二分图（出/入副本）→ 最大匹配 M → 答案 = n−M。

## Q16: 带权点覆盖的 Primal-Dual 算法

### 📖 详细版

**ILP**：min Σ w_v x_v, s.t. x_u+x_v ≥ 1, x_v ∈ {0,1}
**LP**：同上，x_v ≥ 0

**对偶 LP**：max Σ_e y_e, s.t. **Σ_{e∋v} y_e ≤ w_v**, y_e ≥ 0

> 直觉：边"付钱"给端点，每个点获得的总钱数 ≤ 其权重。

#### Primal-Dual 算法

```
初始化：y_e = 0, x_v = 0
WHILE 存在未覆盖边 (u,v) (即 x_u=x_v=0):
    增加 y_{uv} 直到 u 或 v 的约束变紧
    (Σ_{e∋u} y_e = w_u 或 Σ_{e∋v} y_e = w_v)
    将变紧的点选入覆盖 (x_v = 1)
```

#### 近似比 = 2 的证明

1. **对偶可行**：算法始终维护 Σ_{e∋v} y_e ≤ w_v ✓
2. **Σ w_v x_v ≤ 2 Σ y_e**：
   - 选中点 v：w_v = Σ_{e∋v} y_e
   - Σ_{v∈C} w_v = Σ_{v∈C} Σ_{e∋v} y_e ≤ **2 Σ_{e∈E} y_e**（每边最多被两端点各计一次）
3. **弱对偶**：对偶可行值 ≤ OPT_LP ≤ OPT
4. ∴ **ALG ≤ 2·OPT** ✅

---

### 📋 极简背诵版

- 对偶：max Σ y_e, s.t. Σ_{e∋v} y_e ≤ w_v（边付钱给端点）
- 算法：提未覆盖边的 y_e 到点约束变紧 → 选变紧点
- 近似比 2：Σw_v = Σ Σ_{e∋v} y_e ≤ **2 Σ y_e** ≤ 2·OPT
- 不需要解 LP，逐步构造

> **速记**：边涨价到端点"付不起"→选该端点。总费 ≤ 2×边总付款 ≤ 2·OPT。

## Q17: Set Cover 的 LP 松弛与随机取整

### 📖 详细版

**ILP**：min Σ c_S x_S, s.t. Σ_{S∋e} x_S ≥ 1, x_S ∈ {0,1}
**LP**：去掉整数约束，x_S ≥ 0。设最优解 x*_S。

#### 随机取整算法

每个 S 独立以概率 **x'_S = min{1, α·x*_S}** 选择，α = Θ(log|U|)。

#### 覆盖概率

对元素 e：P[e 未被覆盖] = Π_{S∋e} (1−x'_S) ≤ Π_{S∋e} exp(−α·x*_S)
= exp(−α Σ_{S∋e} x*_S) ≤ **exp(−α)**（因 LP 约束 Σ x*_S ≥ 1）

取 **α = c·ln|U|**：P[e 未覆盖] ≤ |U|^{-c}

**联合界**：P[∃未覆盖] ≤ |U|^{1−c} → c≥2 时 → 0

#### 期望成本

E[成本] = Σ c_S·x'_S ≤ **α Σ c_S x*_S = α·OPT_LP**

α = Θ(log|U|) → **O(log|U|)-近似** ✅

---

### 📋 极简背诵版

- 每集合以 **min(1, α·x*_S)** 概率独立选
- P[e未覆盖] ≤ exp(−α·Σx*_S) ≤ **e^{−α}**
- 取 **α = Θ(log|U|)** → P[e未覆盖] ≤ 1/|U| → 联合界全覆盖
- 期望成本 = α·OPT = **O(log|U|)·OPT**

> **速记**：LP 分数解 × α 概率取整 → α=Θ(log n) 全覆盖 → O(log n)-近似。

## Q18: 带点容量和需求的最小费用运输问题

### 📖 详细版

**问题**：工厂 → 仓库 → 商店。工厂供 s_i，商店需 d_j，仓库容量 c_v，边容量 u_e + 费用 a_e。

#### 建图

**节点**：
- 超级源 S、超级汇 T
- 工厂 F_i，仓库 W_v（拆 W_v^{in}→W_v^{out}），商店 R_j

**边**：
1. **(S → F_i)**：容量 = s_i，费用 = 0
2. **(F_i → W_v^{in})**：容量 = u_e（或 ∞），费用 = a_e
3. **(W_v^{in} → W_v^{out})**：容量 = **c_v**（仓库吞吐上限），费用 = 0
4. **(W_v^{out} → R_j)**：容量 = u_e，费用 = a_e
5. **(R_j → T)**：容量 = **d_j**，费用 = 0

#### 求解

- **最小费用流**（Successive Shortest Path / Capacity Scaling）
- 若最大流 = Σ d_j → **可行**，最小费用为答案

#### 正确性

- S→F_i 限制供应 ≤ s_i
- W_v 拆点保证流量 ≤ c_v
- R_j→T 容量 = d_j 保证需求被满足
- 边费用如实反映运输成本

---

### 📋 极简背诵版

**建图**：
- S → 工厂（容量 s_i, 费 0）
- 工厂 → 仓库_in（容量 ∞/u_e, 费 a_e）
- **仓库_in → 仓库_out**（容量 c_v, 费 0）← 点容量
- 仓库_out → 商店（容量 ∞/u_e, 费 a_e）
- 商店 → T（容量 d_j, 费 0）

**求解**：最小费用最大流。满流 Σd_j = 可行。

> **速记**：超源→工厂(cap=s_i)→仓库拆点(cap=c_v)→商店→超汇(cap=d_j)。min-cost max-flow。
