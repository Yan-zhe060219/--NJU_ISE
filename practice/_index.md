## 使用流程

### 1. 拖入文件
将 PDF/PPTX 文件放入对应课程的对应子文件夹。

### 2. 运行分析
```
/learn practice/<课程名>/
```
或直接说"分析数据库的练习资料"。

### 3. 产出物

每科生成一份 `exam-intel.md`，包含：

- **高频考点热力图**：每道真题/思考题 → 映射到笔记章节 → 统计频次
- **题型分布**：选择/填空/简答/计算/设计/证明，各占多少
- **深度评估**：概念背诵级 vs. 应用级 vs. 推导证明级
- **优先级重新排序**：基于真题频次，重新排列该科笔记的复习优先级
- **模拟自测题库**：从往年卷提炼，按章节组织

### 4. 反馈到复习计划
分析完成后，自动更新 REVIEW.md 中对应课程的优先级：
- 高频章节 → 升为 Phase B 预加载 / Phase C 重点
- 从未考过的章节 → 降为浏览级

## 重要规则

### 往年卷使用策略
- 🟢 **分析用**：留 1 份最新/最权威的，其余全部用于拆解分析
- 🟡 **模考用**：最新那份在 Phase C 考前 1-2 天做限时模考
- 🔴 **不做完**：不要把往年卷当练习册全刷完——留一份模考比刷十份更有价值

### 复习思考题（数据库特有）
- 每章的复习思考题是**老师心目中的考点清单**
- 优先于往年卷——因为思考题覆盖更全、更贴近教学意图
- 直接逐章做，做不出来的标记为 Phase B 重点突破

### 混乱资料的整理
数据库资料来自多个来源（本院/外院/同学/老师），分析时我会：
1. 先识别来源（文件名、内容特征）
2. 标注可信度（本院老师 > 本院同学 > 外院）
3. 交叉验证：多个来源都出现的考点 = 几乎必考

## 与三阶段复习计划的关系

```
Phase A（维持期）→ 处理 + 初步分析资料，生成 exam-intel
Phase B（定向期）→ exam-intel + 划重点，双重锁定考试范围
Phase C（冲刺期）→ 模考 + 复习思考题逐章过
```
