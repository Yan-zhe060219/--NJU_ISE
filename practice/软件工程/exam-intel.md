# 软件工程与计算 II · 考情分析

> 来源：老师口头透露的题型结构。软工二课程改革后无往年卷参考，此信息为最可靠的考试信号。

## 题型结构（按顺序）

### 1. 名词理解 / 概念题
- 软件工程是什么？（基础概念）
- 名词翻译（2-3 题）
- 纯概念题

### 2. 需求分析 / 设计 / 应用题
- 给背景场景
- 涉及需求分析 → 设计 → 应用全流程

### 3. 设计模式
- 通常问"要不要用设计模式？"（答案一般是 **要**）
- 四个设计模式中选一个考
- 如果考新设计模式会给背景说明

### 4. 软件构造 / 代码设计
- 看代码找问题
- 代码坏味（smell）
- 对齐、分隔等代码规范问题

### 5. 测试题
- 给一个场景，设计测试用例
- 画流程图
- 计算圈复杂度
- 与往年卷类似（参考 `往年卷/2020软件工程与计算IIA（重点看）.pdf`）

### 6. CHI / 人机交互
- 给截图，问人机交互设计
- 考察几个人机交互原则
- 可能是近年新增题型

## 备考策略

| 题型 | 对应笔记章节 | 优先级 |
|------|-------------|--------|
| 名词理解 | 软件工程概述、基本概念 | 🔴 必背 |
| 需求/设计/应用 | 需求工程 + 体系结构设计 + 详细设计 | 🔴 核心 |
| 设计模式 | 设计模式章节（4选1） | 🟡 理解+应用 |
| 构造/代码设计 | 软件构造 | 🟡 实践 |
| 测试 | 软件测试（白盒+黑盒） | 🟡 练习流程图+圈复杂度 |
| CHI | 人机交互 | 🟢 浏览原则即可 |
