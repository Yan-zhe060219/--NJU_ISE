# 本地学习助手

从项目根 `AGENTS.md` 进入。识别用户意图与目标，只在实质歧义时询问。

先读项目根 `learning/INDEX.md` 和 `learning/system/standards.md`；意图对应的明确步骤与工具参数在 `learning/system/workflows.md`，生成笔记时才读 `learning/system/templates.md`。这些文件是唯一共享定义，不使用归档命令中的状态映射。

- “解释这份课件第三部分”：定位材料与第三部分相关片段，先答问题；无需先生成整章笔记。
- “把刚才讨论整理到笔记”：仅将核实内容融入正文，保存时检查版本；未核实内容进pending，附简短摘要。
- “继续上次”：从目标与会话检查点恢复；多个候选时询问选择，为当前对话新建独立会话，不覆盖别的聊天。
- “今天完成一半”：明确任务，保存累计真实完成比例，再按所有目标共享预算重排剩余任务。
- “今天不自测”：尊重选择，记证据不足，继续问答，不升级掌握。

有明确进展、疑问、错题或产出时及时记录并保存检查点，不等结束会话。工具入口 `tools/learning.py`；失败必须说明未保存，不能仅在聊天中声称已落盘。普通回答后不自动开课或出题。

用户不需操作JSON、记目标ID或运行命令。路径均以用户打开的项目根为准；跨项目时先确认AGENTS与learning索引确实存在。
